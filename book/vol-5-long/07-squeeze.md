# 5.7 Consolidation Squeeze

> 一句话：横盘箱子两边都能破。课程只做上沿被接受；立刻跌回箱子就是失效。图表证明不了里面堆了空头。

开盘先弱后强，那是前一章的 Red-to-Green：线画在昨天收盘价上。本章的线是一根你事前画好的**水平箱子**。课程把它叫 Consolidation Squeeze。名字里的 squeeze 是机制假说，不是观察。

长时间横盘，价格在窄区间里来回。多空仓位**可能**在里面积累。若价格向上突破，原先依赖上沿做空的人**可能**止损回补，进一步增加买单。这两句都是解释。能写进计划的只有：箱子画在哪、什么叫上沿被接受、什么叫重新失守、每股风险能不能下单。

本章只做这一个知识点。旗形、贴顶、红翻绿、开盘区间、突破后回踩，全部另开桶。统计时不要因为后来涨了，就把任何横盘后的上涨都改名为 squeeze。

## 5.7.1 这个名字在说什么

课程画面是：价格先走成可识别的水平上下沿，持续时间足够让你在突破**之前**把箱子画好，量通常萎缩，然后向一侧离开。离开之后，波动和成交可能突然变大。

![横盘方向未知，只做上沿被接受](../assets/squeeze-box.svg)

画面重点不是复制某一种 K 线形状。要找的是三件事：持续时间、水平边界、突破后是否扩张并被接受。

| | |
|---|---|
| 形状 | 可识别的水平上沿和下沿；持续时间足够让你事前画好（「足够」自己定义并固定） |
| 触发 | 区间上沿被突破，并且在上方被**接受** |
| 失效 | 价格重新被箱子接受；立刻跌回是最干净的失败 |
| 常见失败 | 影线插过上沿又回来；突破后立刻跌回；低量箱子里放大仓，破位滑点很差 |
| 方向 | 下沿如果是平的，方向事先未知；课程选择**只做向上突破** |
| 不做 | 箱子里猜方向；把「里面一定有空头」当入场条件；失效之后还拿着等 squeeze |

「Consolidation」是观察：高低点大致水平、振幅变窄、量常常下降。「Squeeze」是故事：空头被挤着回补。本书保留课程的名字，但六栏里只填观察。日志的 Setup 一栏可以写 `consolidation-squeeze`，Trigger 栏不能写「空头开始回补」。

红翻绿和横盘挤压不要丢进同一个桶。前者的位置昨天就知道；后者的箱子是当天（或盘前）走出来的。开盘 10 分钟启发式是红翻绿的过滤，不是本章的过滤。

## 5.7.2 箱子怎么画

先声明周期。1 分钟上走了四十分钟的箱子，和 5 分钟上七八根小实体，可能是同一段价格，统计仍要写清你用的是哪一张图。触发和失效必须来自**同一个周期**。不要 1 分钟看见上沿被插过就买，止损却放到 5 分钟箱子的下沿还不减股数。

可识别的箱子通常同时满足：

- 多个高点大致落在同一水平，而不是一串抬高的高点；
- 多个低点大致落在同一水平，而不是一串抬高的低点；
- 单次来回的振幅比前面的冲动段小；
- 你能在突破前用两条水平线把上下沿标死，而不是突破之后再把线挪到「刚好包住」。

高低点都没有明显抬高或降低时，先标为横盘，比强行猜方向更安全。横盘内部的某一根绿 K 或红 K，不能单独定义新趋势。真正的结构变化要等价格离开区间，并且离开之后还留在那一侧。

「足够长」不是物理定律。课程示例常常是盘中走了几十分钟、让人来得及画线的那种。你必须自己写死一个下限，例如：

```
周期 = 1 分钟
最少已收盘根数 = 15
上沿至少被测试 2 次
下沿至少被测试 2 次
上沿波动带宽度 <= 你事先写的点数（或箱子高度的一个比例）
```

这些数字全部是启发式。改完写进计划，用自己的样本校准。不要盘中临时把「15 根」改成「8 根」，只为了让眼前这一笔合格。

上沿不是一根 K 的最高影线。更稳的画法是：取反复受阻的成交密集区上沿，允许几美分的毛刺，但不要把一次远离的插针算进箱子高度。下沿同理。箱子是区域，不是精确到每一跳的铁轨。

下面这些**不是**本章的箱子：

| 你看见的 | 为什么不是 |
|---|---|
| 只有上沿平、低点一节节抬高 | 那是贴顶，见突破章 |
| 前面有明显旗杆，旗面是浅回调 | 那是旗形 |
| 高低点都在漂移，两条线要斜着画才包得住 | 趋势通道或杂波，不是水平箱子 |
| 只碰了一次高、一次低 | 还没有可识别的区间 |
| 开盘后固定 5 / 15 分钟的第一段 | 那是 ORB，时长必须事前写死，另开桶 |
| 线画在昨收上，没有当天走出来的上下沿 | 那是红翻绿的位置 |

画线时记下：该上沿被测试几次、当时有没有明显成交、你用的是已收盘高点还是仍在变化的影线、箱子是否贴着 VWAP / 整美元 / 盘前高 / 日线供给。线的作用是限定决策，不是让图表事后解释完整。

## 5.7.3 图表证明不了「里面堆了空头」

更严谨的说法始终是：新增买盘，加上**可能的**空头回补，一起把需求推高。图表本身通常**证明不了**「这里堆了很多空头」。

下面任何一条单独出现，都不是 squeeze 的证明：

- 箱子走得很久；
- 上沿附近有可见卖单；
- 借股费变贵，或 locate 不好找；
- 屏幕上亮了 SSR；
- 突破后价格加速；
- 聊天室或扫描器标题写了 squeeze；
- 历史 short interest 看起来高。

SSR 只限制普通空单必须高于当前最优买价，不保证上涨，也不制造挤压。借股贵只说明做空成本高，不说明净空头还在里面、也不说明他们必须现在回补。Level 2 上一张大卖单可能成交、撤单或被冰山补充；截图不能说明下一秒它还在。历史 short interest 有滞后，口径也不等于「此刻站在这只股票上沿的空头」。

可观察事实应写成：

- 价格还在事前画好的上下沿之间；
- 量相对箱子早期是萎缩还是已经重新放大；
- 上沿被穿过之后，有没有在上方接受成交；
- 回落有没有把上沿还回去；
- 点差和深度能不能按计划进出；
- 上方到下一层清楚阻力还有多少空间。

不要用 SSR 标签去追所谓挤压。不要因为「空头必须回补」而在失效之后还拿着。不要由换手率或成交量直接推断还剩多少空头。能进日志的是上面那串观察，外加一句注释：「当时我猜有回补，证据是什么，猜测是什么。」

机制假说可以帮你提出问题，不能当 Trigger。问题可以是：如果上沿被接受，那些把止损放在上沿之上的空头会不会成为额外买盘？答案只能由后续成交回答，而且即使上涨，你也分不清多少来自回补、多少来自新增多头、多少来自做市或对冲。

## 5.7.4 区间两边都能破：只做上沿是风险选择

下沿如果是平的，方向事先未知。箱子越长，不代表一定向上。向下破同样合法。多头止损若堆在下沿之下，破位后也可能加速——那是向下的对称故事，同样证明不了「里面堆了很多多头」。

课程选择**只做向上被接受的突破**。这是风险选择，不是预测。做多这本书的仓位、热键、停牌预案，都按向上失败来写。箱子下沿被接受，对本章来说不是一笔空单，而是「这一笔不做」。若你另有做空计划，那是卷六的新六栏：locate、借股费、SSR、向上跳空尾部。不能把多头箱子的规则上下翻转就开空。

因此：

```
箱子还在走      → 仓位默认是 0
上沿被接受      → 才谈本章的多单
立刻跌回箱子    → 本章失效，先走
下沿被接受      → 本章没有多单；不自动反手
```

不要在箱子里做「支撑多、阻力空」的网格，还把两边都记成 squeeze。那种做法的假设是区间会维持，和「等离开区间」是相反的赌注。若你真要在区间内做支撑，风险必须放在明确下沿下方，并且那是另一张卡，不要借用本章的名字。

只做一个方向，样本会丢掉所有向下破的「本可以做对」。这正是代价：你用放弃下沿来换更简单的规则和更少的做空机械风险。复盘时把向下破标成 `not-in-play / breakdown`，计入命中率的分母，不要假装当天没出现过箱子。

## 5.7.5 触发：上沿被接受

水平高点被穿过只是触发的候选。之后能否在新价位**接受成交**，才决定质量。

![左：影线试探。右：实体站上才是接受](../assets/wick-vs-acceptance.svg)

一根长上影穿过上沿又收回箱子，是试探，不是接受。接受看起来更像：

- 至少一根你事先写死的确认方式成立：已收盘实体站在上沿之上，或回落不把上沿还回去；
- 随后的成交有一部分发生在旧上沿上方，而不只是扫了最高价；
- bid 有机会抬到旧上沿附近，而不是立刻撤回到箱子中部。

用未收盘 K 线的最高价当「已经突破」，会把大量假信号算进样本。课程里「第一根创新高」的定义是：当前 K 第一次穿过前一根**已收盘**高点，它不要求当前这根先收盘——那是另一种触发写法。两种都合法，必须写死一种，分开统计。

本章建议你先选下面之一，不要盘中混用：

| 版本 | 触发怎么写 | 代价 |
|---|---|---|
| 收盘确认 | 1 分钟（或你声明的周期）收盘站在上沿之上 | 晚一点，少吃假突破，也可能错过第一跳 |
| 回踩确认 | 先有一次站上，回到上沿附近守住再抬高 | 失效更近，但常常不给回踩 |
| 触价穿越 | 成交出现在上沿之上一个最小跳动 | 更快，假信号和滑点都更多 |

「被接受」不是感觉。把它写成可复现的句子。例如：

```
触发 A：已收盘 1 分钟收盘价 > 箱子上沿，且实体下沿不低于上沿
触发 B：上沿之上出现成交后，回落到上沿 ± 你写死的带宽内再抬高，回踩低点未回到箱子中部
```

A 和 B 是两笔不同的 setup。成功的 A 不能拿来给失败的 B 开脱，反过来也不行。

突破时还要看流动性够不够你进出。上沿被一根极快的 K 打穿、点差已经从 0.02 变成 0.10，理论触发已经发生，可执行触发未必还在。限价可以管最坏买价；管不住的那一截，计入滑点，不能靠加股数补回来。

## 5.7.6 失效：立刻跌回箱子

本章最干净的失败是：上沿刚被穿过，价格马上回到箱子里面，并且在箱子里被接受。

![突破后没有接受，跌回箱子](../assets/bull-trap.svg)

Trap 发生在真实突破尝试之后，不是任意一根反向 K。成功突破和失败突破的前半段长得很像，所以必须以接受作为分界。突破发生前，你无法确定它一定失败；也不要为了「抓 trap」去预判。

| | 更像真突破 | 更像立刻失败 |
|---|---|---|
| 突破后 | 在新价位接受成交，量能跟上且价格有推进 | 立刻跌回箱子内 |
| 回落 | 守住旧上沿，量收缩 | 直接穿过刚破的上沿 |
| 再上冲 | 有新增成交 | 没有新增量能，或高点更低 |
| 盘口 | bid 抬到旧上沿附近 | 点差拉开，深度撤到箱子中部 |

立刻跌回之后，先执行多单止损。不要因为还在等 squeeze 而把失效往下挪到箱子下沿——那是把一笔假突破改写成「我其实在做整个箱子」。若你一开始就把失效写在下沿，那是另一套风险，股数必须按整段高度算，而且假突破时你要扛过整个箱子。

时间也可以写成失效。价格勉强站在上沿之上，却走不动、量回落、来回扫上沿，过了你事先写的分钟数仍没有推进，按时间退出。横盘既可能蓄势，也可能买盘衰竭。「还没跌」不是继续持有的理由。

![重要位置短暂越过，放量大红 K 压回](../assets/high-volume-false-breakout.svg)

放量也可能是顶部换手。高量但价格不再上涨，不能只把高量视作确认。卖盘很大却不涨、旧上沿没有转支撑、随后更低高点再跌回箱子，都是失败特征。

失效触发就走。不能因为「空头还没挤完」而扩大亏损。快速反复会显著增加滑点和追涨杀跌，仓位应比平稳行情小。

## 5.7.7 三种入场必须分开记账

突破章的三种入场，在这里要更严。

![预判、穿越、回踩](../assets/three-entries.svg)

| 入场 | 在本章里意味着 | 主要风险 | 能不能算 squeeze |
|---|---|---|---|
| 预判 Anticipation | 还在箱子里、上沿下方就买 | 突破从未发生；你在猜方向 | **默认不算。** 这是区间内做多 |
| 穿越 Trade-through | 上沿被穿过时买 | 滑点、假突破、追高 | 可以，用穿越规则统计 |
| 回踩 Retest | 先接受，回到旧上沿再买 | 可能不给回踩 | 可以，另开桶 |

提前进入可以改善均价，也承担「向上突破从未发生」的风险。对平底箱子，这个风险不是小概率注释，而是结构本身：下沿同样可能先破。因此本章的默认 No-trade 包含：还在箱子里就开多。

若你坚持做「上沿下方几美分的预判」，必须同时满足：失效不再是整段箱子，而是最近一次抬高的微低点；股数按这个更近的失效算；日志名字不要再叫 consolidation-squeeze。它更接近贴顶的预判，或普通支撑多。

穿越和回踩可以写进同一份总计划，样本必须分开。回踩的前提是：**前面真的发生过一次被接受的向上离开**。没有这一步，后来无论跌回上沿多少次，都不是回踩，而是箱子还在继续。

卖出后把心理止损调到平均成本，只是价格上的保本；费用与滑点仍可能使净结果为负。假突破后加回，会产生一串不同 setup，不能合并成一笔漂亮的大赢家。

## 5.7.8 和贴顶、旗形、红翻绿、ORB 差在哪

名字可以重叠，假设不能重叠。入场前写死你在做哪一张卡。

| Setup | 怎么认 | 方向事先知道吗 | 典型失效 |
|---|---|---|---|
| 本章：平底箱子 | 上沿平、下沿也平 | 不知道 | 重新被箱子接受 |
| 贴顶 Flat top | 上沿平，**低点抬高、回落变浅** | 偏向上的整理 | 最近抬高的低点下 |
| 旗形 | 先有旗杆，再有缩量旗面 | 偏延续前一段上涨 | 旗面低 |
| ABCD | A→B 推动，C 回撤，穿 B 才触发 | 偏延续 | C 低点 |
| 红翻绿 | 线是昨收，先下后上 | 位置已知，方向仍要接受 | flush 低或你写死的结构 |
| ORB | 开盘后固定时长的第一段 | 两边都能破；课程多做上破 | 区间另一端（必须事前写时长） |
| 微回撤 | 强趋势里停 1–2 根 | 已经在趋势里 | 停顿低点 |
| 突破后回踩 | 先有被接受的突破，再回旧上沿 | 假设突破仍有效 | 回踩低被向下接受 |

只满足平顶、低点没有抬高的，是「反复冲高失败」，不是 flat top，也还不是高质量箱子——它可能只是上沿供给还在。多次测试也可能把买盘耗尽，或专门制造假突破。不能机械认为「测得越多越容易 squeeze」。

旗面若是斜的、低点抬高，不要为了用 squeeze 这个名字把线画成水平。ORB 的「区间」来自时钟，箱子的区间来自价格自己走出来的水平。盘前箱子和开盘后箱子分开统计：盘前深度更薄，点差更宽，同一套股数会错配。

同一段走势可以事后被叫成三种名字。必须在事前写死。否则每笔都能在事后找到一个赢的叫法。

## 5.7.9 量能：萎缩是配料，不是许可

![左：放量且推进。右：成交很多却走不动](../assets/volume-progress.svg)

整理区里量能逐步萎缩，是很多突破 setup 的配料，不是充分条件。量缩的解释是抛压可能较轻；它仍可能只是买方消失。箱子走得又长又静，注意力也可能已经离开这只股票。

看量时问三个问题：

1. 和箱子早期比，是扩张还是萎缩？
2. 和这只股票平时同一时段比，是否异常？
3. 放量之后价格有没有推进？还是成交很多却走不动？

突破没有新增量能，后续跟随可能不足。但放量也可能是顶部换手。量是上下文，不是许可。绿量柱也不等于这些成交都由「买方主动」发起——每一笔成交同时有买卖双方。

相对量要和日内时段一起看。开盘前十五分钟的「缩量」和中午的缩量不是同一个基准。把开盘冲动段的量拿来要求中午箱子「必须放量三倍」，会滤掉所有可做的中午样本，或反过来让你在已经死掉的股票上等待一个不会来的放量。

可测试的量过滤（启发式，改完必须固定）：

```
箱子后半段均量 < 前半段均量
触发那根的量 > 箱子后半段均量
触发后 N 根内，价格仍留在上沿之上
否则按时间退出
```

不要把「量能顺序漂亮」加成独立概率。量和价格来自同一条路径。

## 5.7.10 低量箱子与滑点

低量横盘里放大仓，破位时点差会很差。先检查真实可成交规模。

典型错配是：早上这只股票能做你习惯的股数，中午箱子里还用同一股数。箱子里打印的量已经掉到每分钟几百股，可见深度只有两三百股，你却仍按开盘动量下单。上沿一旦被打穿或跌回，点差可能从 0.02 跳到 0.08，止损那一跳不再是图上的线。

先用当前深度问：止损那一刻，谁接你的卖单？

| 检查 | 过不了就怎样 |
|---|---|
| 最近若干根的成交股数能否覆盖你的计划股数 | 减股或放弃 |
| 点差是否已经占掉计划 1R 的明显比例 | 放弃 |
| 上沿附近可见深度是否稳定，还是一碰就撤 | 减股；不要市价追 |
| 是否靠近 LULD 上轨，计划止损覆盖不了停牌第一跳 | 仓位可以是 0 |

```
股数 = min(
  单笔可亏 ÷ (入场 − 失效 + 滑点预算),
  当前可成交深度给出的上限,
  你为低量时段写死的更小上限
)
```

滑点预算要用这类箱子自己的样本，不要借用开盘红翻绿的 0.02。低量破位的尾部更肥。个人上限应更低；halt 暴露时可以直接是 0。

可成交限价限制最坏买价。预设若未成交就放弃，不能顺着上沿之上无限改价追。卖出止损同样：图上的失效价不是最大损失保证。停牌、跳空、深度消失，都会让实际亏损大于计划风险。

## 5.7.11 失效太远时：整段箱子往往下不了单

平底箱子的「结构失效」若写在下沿，每股风险等于箱子高度加滑点。对小账户，这常常已经远到做不了。

这不是让你把止损挤进噪声区。选项只有三个：

1. 箱子内部已经走出抬高的低点，你把失效收到这个低点下方——此时形状正在变成贴顶，应改名、改桶；
2. 只做回踩版，失效收到回踩低附近；
3. 放弃。空间不够不能靠加股数补。

不要第四条：嘴上说失效在下沿，仓位却按下沿算太大，于是偷偷把止损挂在箱子中部。中部没有结构意义。扫到中部你说「还没失效」，跌到下沿你又说「滑点太大」——两头都不是计划。

入场离上沿已经很远，也是追。上沿 6.40，你买在 6.58，失效还在 6.20，你不是在做箱子突破，你是在追已经离开的价格。要么等回踩，要么承认没有近的失效，空手。

上方空间同样要先量。突破上沿之后立刻撞上整美元、盘前高、HOD、日线供给或 LULD 上轨，理论 2R 不存在。形态再像 squeeze 也不做。多个位置重合提高关注度，上方卖压也会更集中，必须看成交是否真的推进。

## 5.7.12 数字例：箱子 6.20–6.40，穿越版

教学用整数，不是某只股票的行情。

箱子 6.20–6.40 走了四十分钟，1 分钟图，量逐步萎缩。上沿在 6.38–6.40 被测过三次，下沿在 6.20–6.22 被测过三次。你事前把上沿标在 6.40，下沿标在 6.20。上方下一层清楚供给在 6.70。单笔可亏 50 美元。滑点预算先写 0.03——这是启发式，要用自己的破位样本改。

**穿越版。** 6.40 之上出现接受，你的成交在 6.43。

若失效写在下沿 6.20：

```
每股风险 = 6.43 − 6.20 + 0.03 = 0.26
股数     = 50 ÷ 0.26 ≈ 192
到 6.70 的空间 = 0.27，大约 1R，勉强
```

对很多小账户，0.26 已经太远，而且立刻失败时你要先扛回箱子里再走到 6.20。更常见的诚实结论是：整段高度不做穿越。

若箱子内部后半段低点已经抬到 6.32，你把失效收到 6.32 下：

```
入场 6.43，失效 6.29（6.32 − 0.03）
每股风险 = 6.43 − 6.29 + 0.03 = 0.17
股数     = 50 ÷ 0.17 ≈ 294
```

这一笔在日志里不应再叫「纯平底 squeeze」。低点已经抬高，它更接近贴顶穿越。两种混在一个胜率里，你永远不知道到底哪张卡在工作。

下沿是平的，所以向下破 6.20 同样合法。你选择只做向上，是风险选择。不要在复盘时因为后来涨到 6.70，就说「当时方向其实很明显」。

## 5.7.13 同一箱子的回踩、立刻失败、向下破

还是 6.20–6.40。四种后续必须分开写，不能事后挑一个好看的。

**回踩版。** 先有一根 1 分钟收在 6.46，回落到 6.41–6.43，再抬高。你买在 6.44。失效可以收到回踩低 6.40 下方加滑点，例如 6.36。

```
每股风险 = 6.44 − 6.36 + 0.03 = 0.11
股数     = 50 ÷ 0.11 ≈ 454
到 6.70  ≈ 2.3R
```

这是另一笔。不能和穿越共用胜率。若回踩直接打回 6.33，说明上沿没有转支撑，按失效走，不要改口说「还在箱子里做支撑」。

**立刻失败。** 你按穿越在 6.43 买了。下一根打到 6.48 又收回，第三根实体落回 6.35，箱子内部重新接受。计划若写「重新被箱子接受即失效」，现在就走。成交可能在 6.37。

```
计划亏损 ≈ (6.43 − 6.37) × 股数，再加费用
```

走了就是执行对了。后面如果再从 6.28 拉到 7.00，那是下一笔的事，与这一笔的评分无关。不能因为仍期待 squeeze 而拿到 6.20 以下。

**向下破。** 上沿从未被接受。价格从 6.28 直接打穿 6.20，1 分钟收在 6.14，随后继续。本章仓位应是 0。把它记成 `breakdown`。不要补一句「早知道该空」。若你当天另有空头卡并且事先写了下沿被接受才空，那是另一行日志。

**上沿假突破后又向下破。** 先扫 6.44，立刻回到箱子，再破 6.20。两段都不是本章的多单。第一段若你已经进了，按立刻失败处理；第二段不要为了摊平改成「反手」。反手是新的一笔。

把这四张图都收进样本。只留最后上涨的那张，squeeze 会看起来像印钞机。

## 5.7.14 数字例：箱子太高、空间不够、午后死掉

**太高。** 箱子 8.00–8.60，走了五十分钟。上沿被接受，入场 8.64。失效若在 8.00，每股 0.64 加滑点。可亏 50 只能做约 70 股。下一层阻力在 8.78，空间 0.14，远不到 1R。结论：不做。不要改成「目标看昨天的 9.50」来把盈亏比画好看——昨天的 9.50 中间隔着 8.78 的供给。

**贴着整美元。** 箱子 4.80–4.98，上沿几乎就是 5.00。突破 4.98 立刻面对整美元供给。要么把触发写成「5.00 被接受」，失效用箱子内部最近低点；要么放弃。不要在 4.99 市价，止损还放在 4.80。

**午后死掉。** 上午曾经 in-play，中午箱子漂亮，量已经掉到全天最低。上沿被一根浅浅的绿 K 穿过，随后平行走了十分钟没有任何推进。按时间退出。不要因为箱子「还没坏」就看到收盘。注意力离开之后，假突破的滑点往往更差，不是更好。

**开盘后过早画箱子。** 9:35 你根据五根 K 画了 3.10–3.22。这不是「足够让你事前画好」的箱子，这是开盘噪声。它更接近 ORB 或开盘失败，不要标成 consolidation-squeeze。开盘前几分钟 VWAP 样本也少，不要把早期 VWAP 当箱子的第三边。

## 5.7.15 箱子画在什么位置

形状是箱子。位置是这条箱子贴着什么。位置越有名，突破时越容易猛，上方卖压也更集中。

常见位置：

| 位置 | 它改变什么 | 它不改变什么 |
|---|---|---|
| 贴着 HOD | 关注度高，假突破也猛 | 触发仍是接受，不是「因为是 HOD」 |
| 贴着 VWAP | 均价附近容易来回 | VWAP 不是天然支撑 |
| 贴着整美元 / 半美元 | 心理单和算法单更密 | 整齐数字不是优势本身 |
| 贴着盘前高或昨收 | 和开盘结构重叠 | 必须选一个名字记账 |
| 贴着日线供给 | 上方空间可能不够 | 日线供给不是自动空点 |
| 上午冲动后的中段 | 更像旗面或休息区 | 没有旗杆就不要改叫旗形 |

HOD 会随新高更新。箱子上沿一旦被接受并留下新高，HOD 就变成新的位置，原来的箱子下沿往往已经太远。第一笔 squeeze 结束之后，下一笔要么是回踩旧上沿，要么是新的更小结构，不要把旧下沿一直当止损。

多个位置重合不是独立概率相乘。小周期先破箱子，再接近 VWAP 或 HOD，可能形成连续触发；日志里仍是同一条价格路径上的一次事件，除非你平掉后按新六栏再进。

盘前箱子单独统计。盘前做成的笔，和开盘后同名结构，不要合并。盘前深度通常更薄；若无法用限价控制最坏成交价，就不应以常规时段的仓位照搬。

## 5.7.16 突破之后：阶梯、回踩、停牌、时间

被接受的向上离开，只证明旧上沿这一次没有立刻把价格压回去。它不承诺趋势会走完你想象的 squeeze。

强趋势不是直线。它是推进 → 回踩 → 重新找到支撑。旧上沿成为新支撑候选，要等回踩验证。新低跌破前一有效支撑，阶梯坏了，降低多头预期。

![有效回踩与失败突破不是同一件事](../assets/dip-after-breakout.svg)

大绿 K 后立刻再追一笔，止损往往更远，盈亏比变差。第一笔还在场内时加仓，必须全仓重算风险，见卷四。很多时候正确的第二笔是：减掉穿越仓，等回踩旧上沿——那是 5.4 的突破后回踩，不是本章的第二张 squeeze。

接近 HOD、整美元或历史供给时分批处理。目标先按结构写：至少约 1R 到 2R，或前一个清晰阻力。历史最大涨幅、别人喊的「空头还没补完」，都不能当目标。

进入 halt 按预案处理，不临时扩大风险。LULD 是保护机制，不是上涨确认。恢复交易价格可能向上也可能向下跳空。计划止损在停牌期间无法连续执行，最大损失不再等于图上的止损距离。初学可以把「箱子刚好顶着上轨」直接列为禁做。

时间退出要写进 Exit 栏。例如：接受后 N 分钟仍不能离开上沿一个最小推进，减仓或平掉。横盘突破后重新走平，常常是注意力结束，而不是「更大的 squeeze 在后面」。

假突破之后：

1. 不等待「再给一次机会」；
2. 按失效减仓 / 平仓；
3. 检查是否成为多头陷阱（反转与陷阱那一章）；
4. **不自动反手做空**——反手是新的一笔，要有 locate 和新计划；
5. 记录滑点和「在上方停留了多久」。

1 分钟信号更快但噪音更多；5 分钟更慢，失效距离通常也更大。两种周期的箱子分开统计。

## 5.7.17 六栏：这一张卡怎么写

下单前六栏写不齐，就没有这一笔。形态名只填 Setup。

| 栏 | 本章的填法 |
|---|---|
| Setup | 平底水平箱子 + 你标的位置（HOD / VWAP / 整美元 / 盘前高 / 无） |
| Trigger | 上沿被接受；写死收盘确认、触价穿越或回踩，只选一种 |
| Invalidation | 重新被箱子接受；或回踩版的回踩低被向下接受 |
| Size | 可亏 ÷（入场 − 失效 + 这类箱子自己的滑点），再取深度上限 |
| Exit | 第一目标（清晰阻力或 N 个 R）、分批、时间退出、halt 预案 |
| No-trade | 见下一节，抄进计划后不要盘中删 |

一份可复现的最小规格：

```
周期：1 分钟
箱子：上沿 ____  下沿 ____  开始时间 ____  已收盘根数 ____
位置：□ HOD  □ VWAP  □ 整美元  □ 盘前高  □ 昨收  □ 日线供给
触发版本：□ 收盘确认  □ 触价穿越  □ 回踩
入场：____
失效：____
滑点预算：____
股数：____
第一目标：____
时间退出：接受后 ____ 分钟无推进则 ____
halt：靠近上轨则仓位 = 0
```

止损只能往有利方向移（多单往上），不能因为「还没挤完」往下放到更远的下沿。错过就错过。

保本（把止损移到成本）会提高「不亏」的频率，同时提高被扫出后价格继续走的频率。它改变的是分布，不是魔法。是否在旧上沿上移到保本，要单独统计。

## 5.7.18 复盘：把画面停在入场前

事后图很顺。能涨到远处的 squeeze 都会留下漂亮箱子。复盘时把录像停在你打算点买的那一根之前，逐项写：

- 当时箱子的上下沿已经画死了吗，还是后来为了包住插针才挪的？
- 持续时间达到你写死的下限了吗？
- 下沿是平的吗？如果是，你有没有承认两边都能破？
- 触发那一刻，接受已经发生，还是只看到未收盘最高价？
- 你用的是穿越还是回踩？有没有把两种混在一起？
- 对「short squeeze」的判断，哪些是可观测证据，哪些只是推测？
- 上方到下一层阻力是否 ≥ 计划 1R？
- 当时点差和深度能否进出计划股数？
- 如果后面没有那根大绿 K，这笔入场仍合理吗？
- 立刻跌回时，你是按计划走，还是改口在等回补？
- 有没有把红翻绿、ORB、旗形事后改名为本章？

红翻绿是价格相对昨收的状态转换。本章是当天走出来的箱子。真正可重复的是对水平边界、接受、失守和风险边界的组合判断，不是对「空头被挤」的感觉。

「不可交易」和「策略失败」要分开。方向可能向上离开，但流动性不足会使入场和退出质量很差。没有成交容量的理论利润不是可实现利润。把这类样本标成不可交易，计入命中率的分母，不计入可执行期望值的分子。删掉它们，胜率会被人为抬高。

课程录制期的热市样本，不能直接外推到冷市。按市场状态分组。中午低量箱子在热市和冷市的滑点分布不是同一组数。

## 5.7.19 No-trade

出现下面任何一条，本章仓位是 0：

- 上下沿还画不出来，或你正在突破之后改线；
- 还在箱子里，只是觉得「要 squeeze 了」；
- 下沿是平的，你却在上沿下方猜多；
- 上沿只被影线插过，没有接受；
- 接受后立刻跌回箱子，还想加仓摊平；
- 失效只能画在整段下沿，每股风险已经超过你能接受的距离；
- 入场离上沿已远，还用旧下沿当止损；
- 上方清楚阻力比 1R 更近；
- 点差已经占掉计划目标的显著比例；
- 深度接不住计划股数；
- 靠近 LULD 上轨，或正在停牌 / 刚恢复盘口未稳；
- 未核实的重大新闻或 news halt；
- 已达到当日亏损上限；
- 想用 SSR、借股费或聊天室标题代替接受；
- 把红翻绿、ORB、旗形临时改叫 squeeze，只为了让自己有理由下单。

错过一波箱子突破，后面还有回踩和别的结构。箱子不是必须参与的仪式。

## 5.7.20 样本怎么标

每个箱子记一行，包括没交易的。

```
日期 / 代码 / 时段:
周期:
上沿 / 下沿 / 高度 / 根数 / 测试次数:
位置标签（HOD / VWAP / 整美元 / 盘前 / 昨收 / 无）:
量：前半 vs 后半 vs 触发根:
点差：箱子内 / 触发时 / 失效时:
可见深度是否覆盖计划股数:
触发版本（收盘 / 穿越 / 回踩 / 未触发）:
入场 / 失效 / 滑点预算 / 实际滑点:
计划 R / MAE / MFE:
在上沿之上停留了多久:
立刻跌回? 向下破? 不可交易?
对 squeeze 的猜测写在哪、证据写在哪:
是否与红翻绿 / ORB / 旗形 / 贴顶重名:
按规则退出的结果（不是事后最佳退出）:
```

最小训练量写在你自己的计划里。课程爱说的「至少各 20 个」是启发式。按波动状态分组，不要用一个热市月份凑满数字。失败、未触发、不可交易，三格都要留。

期望值仍按卷四算。胜率过 50% 既不是必要，也不是充分。只追「抓住 squeeze」会让人拖延止损。只追纸面盈亏比会忽略目标根本成交不到。

## 先记住这些

- 箱子是观察；squeeze 是假说。图表证明不了空头堆在里面。
- 下沿平，则两边都能破。只做上沿被接受，是风险选择，不是预测。
- 触发在上沿被接受。未收盘最高价不是突破。
- 立刻跌回箱子就是失效。不要因为还在等回补而扩大亏损。
- 预判在箱子里买，默认不是本章。
- 整段高度当止损往往太远：改近并改名，或放弃。
- 低量箱子用开盘的股数，破位时常常没有人接你的卖单。
- 红翻绿、ORB、旗形、贴顶，不要事后改叫 squeeze。

## 不要做的事

- 区间里猜方向。
- 用 SSR、借股费或「空头必须回补」当入场条件。
- 影线插过上沿就市价追。
