# 13.6 用期权做方向（Warrior 叠加）

> 一句话：先有标的 thesis，再选 payoff。价差限制的是到期图上的两边，不是中途的成交、指派和拆腿后的新风险。

卷十至卷十二已经写过合约、Greeks、垂直价差和卖方结构。本章只叠加 Warrior Swing 课里对「用期权表达日线方向」有用的部分：组合单、四种退出、拆腿必须当新仓，以及五种 swing 策略的对照。不把 TSLA 事后大涨写成策略证明。

下单前仍应读 OCC 的 *Characteristics and Risks of Standardized Options*。权限由券商审批。Defined-risk 只表示理论到期图有边界，不保证能在计划价格退出。

## 13.6.1 先回答五个问题再选结构

```text
方向：涨、跌、还是留在区间
波动：你要 IV 升还是降，事件会不会重定价
时间：预期几天走完，到期还剩多少交易日
最大亏损：美元数字，不是「就一张」
指派后你愿意持有什么
```

任意一栏填不出，就还没有结构，只有看法。看法用股票也能表达；期权是在看法上再加时间和波动率赌注。

五种策略不是从保守排到激进，是五种 payoff。Credit 策略常显示较高的小赢频率，长期权常显示较低胜率、单笔潜在收益大。统一用期望值比，不要用胜率选策略：

```text
期望值 = P(赢) × 平均赢 − P(亏) × 平均亏 − 费用 − 滑点
```

还要看偏度、最大连续亏损、保证金上调和相关仓位同时受损。

## 13.6.2 垂直价差：一张表

同一标的、同一到期、不同行权价：

| 策略 | 组合 | 典型方向 | 最大亏损 |
|---|---|---|---|
| Call 借记价差 | 买低行权价 call，卖高行权价 call | 看涨 | 净借记 |
| Put 借记价差 | 买高行权价 put，卖低行权价 put | 看跌 | 净借记 |
| Call 贷记价差 | 卖低行权价 call，买高行权价 call | 看跌 / 中性 | 宽度 − 贷记 |
| Put 贷记价差 | 卖高行权价 put，买低行权价 put | 看涨 / 中性 | 宽度 − 贷记 |

以上都乘合约乘数，并扣费用。只有同到期、同类型的 vertical 才能直接用这张表。日历价差、对角、铁秃鹰要另画。

![牛市看涨借记价差：最大亏净借记，最大赚宽度减借记](../assets/vertical-spread.svg)

Put 贷记价差：

```text
最大利润 = 净贷记 C
最大亏损 = (短 put 行权价 − 长 put 行权价) − C
盈亏平衡 = 短 put 行权价 − C
```

Call 借记价差：

```text
最大亏损 = 净借记
最大利润 = 行权价宽度 − 净借记
盈亏平衡 = 长 call 行权价 + 净借记
```

短 put 行权价在支撑下方，不等于安全。隔夜跳空可以一次性越过两条行权价，直接接近最大亏损。先用到期图算三个数字，再评估中途 Greeks。

方向很强时，借记价差比贷记价差保留更多上行，但最大收益仍被短腿限制。标的很快越过两条行权价时，价差未必立刻等于到期最大值——剩余时间价值还在。不一定要拿到理论最大值；最后一点利润往往用大量剩余风险去换。

## 13.6.3 组合单与单腿裸露

两腿各有买卖价。自然成交区间不是两个 last price 相减。用净借记 / 净贷记的限价组合单，减少一腿成交、另一腿没成交的裸露。

深度不足时，屏幕中间价可能买不到。从保守价格往里挪，不追理论值。成交后立刻核：实际净价格、两腿代码、到期、张数。实际净借记才是这笔的最大亏损。

不要只对单腿设止损。退出看整个价差的可成交净价。分别市价平腿会增加成本和短暂裸露。

## 13.6.4 四种退出，价差共用

1. **价格目标**：达到预定净价格（例如收回约 90% 权利金，或借记价差涨到某净价）；
2. **标的失效**：日线结构坏了，即使期权还没到最大亏损；
3. **时间止损**：预期波动没有按期出现；
4. **事件 / 波动率改变**：财报、IV 或流动性不再是入场时的那张表。

课程里出现过「1:1 止损」和「权利金衰减 90% 后买回」。那是管理规则，不是最大亏损保证。期权价差会因 IV 和流动性跳过止损价。GTC 止损在盘外标的变动、期权市场未开时可能毫无意义。

到期前另查：

- 两腿各是 ITM / ATM / OTM；
- 短腿有没有提前指派风险；
- 是否除息；
- 行权 / 指派后会变成多少股票；
- 账户有没有足够购买力；
- 价差还有没有流动性可平；
- 券商到期截止；
- 是否值得为最后一点利润承担 pin risk。

价差把风险写进结构，不会替你管理到期和订单。

## 13.6.5 拆腿是新仓位

课程有一段不对称铁秃鹰（iron condor）案例：两侧贷记价差的权利金差很多，说明市场对触及某一侧定价更高。标的后来走强，看涨那一侧变成亏损腿；讲师买回短 call、留下长 call，仓位从有限风险的贷记价差变成单独的多头看涨。

这段只保留三条：

- 权利金越诱人，通常对应更高的被触及风险；
- 两侧 credit 不对称时，不要把它当成「均衡的区间交易」；
- 一旦拆腿，payoff、Greeks、最大亏损和退出规则全部重写，不能沿用原价差的止损。

拆腿不是可普遍复制的修复法。一次结果盈利，不能证明以后遇到亏损价差都应该拆掉短腿。它可能把有限风险结构变成另一笔没有事前计划的交易。复盘要比较：初始到期图、逐腿成交、每次改仓后的新图、中途最大风险。不要只用最终净利润或事后最高价后悔少赚。

课程口述的具体行权价和权利金是拆股前历史，不能直接对照今天的标的价格。

## 13.6.6 五种 swing 策略对照

### 6.1 Covered Call

持有 100 股，卖出 1 张 call，收权利金，放弃行权价上方的大部分上行。

```text
到期近似：股票盈亏 + 短 call 盈亏
最大收益 ≈ (行权价 − 股票成本) + 权利金
最大亏损 ≈ 股票跌向零 − 权利金
```

只在「本来就愿意按行权价卖掉股票」时，指派才和计划一致。权利金保护不了大跌。课件用较低 delta、较远虚值降低指派概率；delta 是局部敏感度，不是精确到期概率。「0.20 以下 delta」是课程偏好，不是最优阈值。

股价较强时权利金往往更高，同时你锁住上行的时间也更长。更远到期收更多权利金，锁得也更久。避开财报是课程建议，因为事件会同时推动股价和 IV。

管理：剩余收益很小却仍承担跳空 / 指派，提前平仓往往更合理。除息前，价内短 call 有提前指派风险。复盘必须用「若只持股票」当基准，判断权利金是否补偿了被截断的上行。

### 6.2 现金担保 Put

卖出 put，同时预留大约 `行权价 × 乘数` 的现金。行权价必须是你愿意持有股票的真实价格，不是「权利金看起来高」。

```text
最大利润 = 权利金
盈亏平衡 = 行权价 − 权利金
最大亏损 ≈ 行权价 − 权利金（股票到零）
```

课程用过大约 300 美元行权价、0.50 美元权利金的名义例子：一张对应约 30,000 美元义务，最大收益约 50 美元。风险收益极不对称。「大概率到期归零」不等于有优势，要比较历史尾部亏损和占用资金的机会成本。

调整合约、非 100 乘数会改现金需求。券商显示的保证金可能小于经济损失。压力市里 put 点差拉宽，按中间价想象的买回止损会差一截。到期前也可能被指派。指派后若不愿持有，就不要把它叫作「低价建仓策略」。

### 6.3 贷记价差与铁秃鹰

贷记价差：卖近、买远，限制尾部。铁秃鹰：同时做 put 贷记和 call 贷记。它不是两个胜率相加，而是要求标的到期留在中间。四腿有更多点差、费用和指派管理。财报等大波动会同时威胁任一侧。

不能只写总权利金。要写四个行权价、两个盈亏平衡、两侧最大亏损。短行权价被突破后不一定立刻打到最大亏损，但临近到期时短行权价附近的 gamma 会变敏感。Pin 在两条行权价附近时，不要依赖平台自动给你理论结果。

### 6.4 借记价差

方向信心较强、需要降低权利金、愿意封顶利润时用。长腿提供方向，短腿降低借记。短行权价应结合目标价和流动性，不要只钉在牛旗顶部。

若标的目标低于短行权价，你为用不到的宽度付了钱。深度价内 / 价外腿的点差和未平仓量可能差很多。组合成交后核对实际净借记。

很早超过短行权价时，价差仍受剩余外在价值影响，未必立刻等于宽度。两腿都价内、持有到期，行权与指派可能在股票上对冲，账户仍要按券商流程处理。

### 6.5 单买 Call / Put

权利金可以全部归零。用 put 对冲一个已经存在的大股票仓，和把小账户押在虚值 put 上，工具相同，目的完全不同。低美元报价容易掩盖高归零概率。

到期必须匹配预期时间。震荡区里买期权，会同时遇到方向不明和时间损耗。更长到期减少近期时间压力，但权利金和 vega 更高。消息出来之后再买，IV 往往已经涨过；K 线跌幅不能直接等于期权回报。标的停牌时期权也可能难成交，预设止损无法保证。

单一研究报告、单一成功做空截图，不能当系统。事实、时点、市场是否已定价，要分开核。

## 13.6.7 风险对照表

| 策略 | 主要观点 | 最大收益 | 主要尾部 |
|---|---|---|---|
| Covered call | 温和看涨 / 愿按行权价卖 | 有上限 | 股票大跌 |
| 现金担保 put | 愿按行权价买 | 权利金 | 股票接近零 |
| 贷记价差 | 方向或区间，收权利金 | 贷记 | 跳空至最大亏损 |
| 借记价差 | 明确方向 | 宽度 − 借记 | 借记全损 |
| 长 call / put | 强方向或对冲 | call 理论上行无上限，put 有上限 | 权利金全损 |

## 13.6.8 仓位级 Greeks

不要只看单腿。平台数字是估计。

- Covered call：多头股票 delta 被短 call 部分抵消；
- 现金担保 put：短 put 通常正 delta、负 gamma、正 theta、负 vega；
- 贷记价差：有限风险，到期附近短行权价周围对 gamma 敏感；
- 借记价差：方向 delta，theta / vega 被短腿部分抵消；
- 长期权：常见情况是长 gamma、长 vega、负 theta。

持仓期间每天看净值，不看「我当初是 condor」。拆过腿就按新结构读。

## 先记住这些

- 先有日线 thesis，再选 payoff。
- 三个数字：最大利润、最大亏损、盈亏平衡。
- 组合单减少单腿裸露；退出看净价。
- 拆腿 = 新交易。
- 胜率不选策略，期望值才选。

## 不要做的事

- 用最便宜虚值期权代替买不起的 100 股。
- 把不对称铁秃鹰当成中性区间。
- 亏损后拆掉短腿「博回来」，却不重写最大亏损。
- 只给单腿挂止损。
- 在权利金已经反映消息之后，用标的涨跌幅推算期权收益。
