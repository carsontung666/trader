# 13.4 Swing 基础

> 一句话：Swing 用更长持有期换更低的盘中操作频率，同时买入隔夜跳空、事件和仓位占用。它不比日内更安全，只是风险换了形状。

本章对应 Warrior Swing 课的基础部分。期权合约机制已在卷十至卷十二写过，这里只保留对持有期和载体选择有影响的部分。不把日内小盘的持仓直接改名叫 swing。

## 13.4.1 不是更容易，是另一张风险表

课件认为：日内更容易预测未来几分钟，swing 更容易学、不必高速读 Level 2。这是作者的个人经验，不是普遍难度结论。两者面对的风险不同。

| | 日内 | Swing |
|---|---|---|
| 主要暴露 | 盘中执行、滑点、短周期噪声 | 隔夜跳空、事件、多日状态切换 |
| 操作频率 | 高 | 低 |
| 止损距离 | 通常更短 | 日线上通常更长 |
| 仓位 | 可按短止损放大股数 | 同样 1R 美元只能更少股 |
| Level 2 | 小盘动量几乎必需 | 大盘不必盯每一档，仍要看流动性 |
| 失败后的坏习惯 | 连点、报复 | 把错误仓位改标签隔夜 |

「不需要 Level 2」不等于不需要流动性。进出大仓位仍受买卖价差和成交量约束。日线看起来很宽的突破，盘中可能只有几美分的薄盘口——尤其是中盘股、盘前盘后、或期权腿。

Swing 也不是「没时间做日内的人的替代品」。你仍然要在触发那天看盘或预先写好条件单，仍然要在财报夜做决定。省下的是开盘三分钟的点击密度，不是决策密度。

## 13.4.2 不要把日内小盘直接持有过夜

课程把日内小盘和 swing 的中大盘分开。部分小盘财务弱、可能有 shelf registration，当天已经涨 20%–30% 之后，更不适合因为不愿止损而隔夜。市值不能单独替代 filings、流通盘、债务和催化剂核验，但分类逻辑作为风险过滤是成立的。

日内盈利仓若收盘前没有**独立的** swing thesis，就必须按日内计划退出。不能因为图形还没走到幻想目标，就把标签从 day trade 改成 swing。那是卷八写过的「把亏损仓改成投资」，只是这次可能还带着浮盈。

选择 swing 标的时额外核对：

- 平均成交量和价差；
- 下一次财报、FDA、宏观数据或公司事件；
- 日线 / 周线结构和上方空间；
- SEC 文件、融资与公司行动；
- 板块与指数相关性；
- 隔夜最大可承受跳空；
- 是否允许 / 计划使用期权。

股票池写到可查询。临时因社交媒体热点换到不熟悉产品，会同时改变波动、点差、隔夜风险和你的心理压力。

## 13.4.3 股票与期权是两种载体，不是两种难度等级

![股票近似线性；期权还要过到期和波动率](../assets/swing-stock-vs-option.svg)

股票仓位价值主要随标的价格近似线性变化。期权还受剩余时间和隐含波动率影响。大盘股长期上涨的历史结果，不能说明任意入场都适合 swing。

| | 股票 | 期权 |
|---|---|---|
| 方向表达 | 近似 1:1 delta | 由结构决定 |
| 额外变量 | 分红、借券、融资成本 | 到期、权利金、IV、Greeks |
| 最大亏损 | 理论上到零（多头） | 买方常为已付权利金；卖方完全不同 |
| 隔夜 | 跳空直接打到股份 | 跳空 + IV 重定价 |
| 适合 | 持有期不确定、期权点差宽 | 时间窗明确、不想要整份名义 |

用期权限制投入金额，不等于限制所有策略的最大亏损。卖出裸期权尤其不同。买不起 100 股，不能成为随便买最便宜虚值期权的理由——那是另一笔到期归零概率很高的交易。

Covered call、现金担保 put 看起来「收权利金」，经济上仍承担大量标的方向风险。它们是仓位管理工具，不是无风险利息。

## 13.4.4 Thesis 必须有时间边界

每笔在进入前写：

```text
标的 thesis
入场触发
技术失效
事件日历
预期持有天数
时间止损
价格目标
隔夜跳空额度
仓位大小
载体：股票，或精确的期权结构
```

时间止损不是装饰。如果预期 3–5 个交易日内突破，到了第 5 天仍横盘，就重新评估，而不是无限延长。「还没跌」不是继续持有的理由。横盘消耗的是：资金占用、事件临近、期权时间价值、以及你把注意力绑在一笔没有进展的旧故事上。

预期持有 3 天和预期持有 30 天，是两个策略。后者要过更多个隔夜和至少一次宏观窗口。不要用同一套止损距离和同一张期权到期去覆盖两种时间。

目标价也要有来源：前高、计量波幅、下一档日线阻力。默认「回到历史最高」不是计划。

填满后的样子（数字是教学假数）：

```text
标的 thesis：日线上升结构，回撤后第一根越过前日高
入场触发：盘中穿过 52.00（昨日高）
技术失效：回撤低点 49.80
事件日历：9 个交易日后财报；本周无 FOMC
预期持有：3–6 个交易日
时间止损：第 5 个收盘仍在 52–53 横盘则退出
价格目标：前高 56.40（约 2R 技术），再看日线 58
隔夜跳空额度：按 48.50 压力价算仓
仓位：风险预算 200 美元 / 3.50 = 57 股（取整）
载体：股票（期权点差 0.40，不值得）
```

写不出「9 个交易日后财报」这一行，仓位公式就是假的。时间止损触发时，即使还没碰到价格止损，这笔也结束。结束之后若出现新的第一根新高，那是下一笔，重新写表。

## 13.4.5 仓位按跳空压力算，不只按日线止损

日线止损距离常大于日内止损，仓位自然应更小：

```text
每股技术风险     = 入场 − 止损
每股跳空压力风险 = 入场 − 压力价
仓位股数         = 风险预算 / max(技术风险, 跳空压力风险)
```

压力价可用历史财报跳空、ATR 倍数或情景分析估计，都不是保证下限。财报前的「日线止损在回撤低点」在盘后可能直接被跳过。不愿承担该事件，就在事件前减仓或退出，而不是寄希望于止损单。

同一标的两种算法不能混：

```text
入场 52.00，回撤低点 49.80
技术风险 = 2.20
近几次隔夜最差跳到 48.50，压力风险 = 3.50
风险预算 200 美元
按技术：200 / 2.20 ≈ 90 股 → 技术止损亏 198，跳空到 48.50 亏 315
按压力：200 / 3.50 ≈ 57 股 → 技术止损亏 125，跳空到 48.50 亏 200
```

用 90 股等于你口头承认隔夜、账户上却按白天止损加杠杆。swing 的默认是后一种。压力价也不是地板：停牌、收购失败、融资公告可以跳得更远。账户总过夜风险还要再设一顶：所有 swing 仓的压力亏损相加，不得超过周预算。

指数相关也要加进去。账户里已经有 MES 多头过夜，再满仓做一只高 beta 科技股的日线突破，跳空是同一笔。名义和压力亏损合并，超了就减一边。

期权仓则用整个到期收益分布：

| 结构 | 常见最大亏损 | 仍要单独处理 |
|---|---|---|
| 买入期权 | 已付权利金 | 到期、流动性、提前平仓 |
| 借记价差 | 净借记 | 两腿成交、短腿限制利润 |
| 贷记价差 | 行权价宽度 − 净贷记，再乘乘数 | 跳空到最大亏损、指派 |
| 备兑看涨 / 现金担保看跌 | 接近标的大跌 | 不能只看收到的权利金 |

「账户允许下单」只说明保证金够，不说明损失合适。

相关持仓要合并看。多一只高 beta 科技股、再买同一方向的指数看涨、再留着同方向的期货隔夜，跳空是同一笔宏观赌注。

## 13.4.6 事件日历是仓位的一部分

每晚确认：

- 财报和公司公告；
- 除息；
- 期权到期；
- 宏观数据、FOMC、就业与通胀；
- 行业会议、监管决定；
- 计划外公司行动。

日历决定：仓位能不能过夜、期权还剩多少交易日、IV 会不会在事件前被抬高。技术图形漂亮但明天开盘前有财报，这笔的真实 setup 是「赌财报」，不是「日线突破」。

不想做事件，就写进 No-trade：事件前 N 个交易日不新建仓，已有仓按规则减或平。普通止损管不住盘后。

## 13.4.7 Swing 的执行选择

日线信号至少有三种进法，必须分开记账：

| 进法 | 你在做什么 | 代价 |
|---|---|---|
| 盘中穿过 | 价格越过触发线立刻进 | 假突破更多，隔夜前还有一天波动 |
| 收盘确认 | 等日线收在触发线上方 | 价格更差，假突破少一些 |
| 回踩确认 | 突破后再回踩触发区 | 可能回不来；回来也可能失败 |

课程案例里两种都出现过。不要事后把赚了的那种叫「我的策略」，把亏了的那种叫「执行问题」。日志写明：intraday trade-through 还是 daily close。

小时图、15 分钟图可以优化进出，不能偷偷把日线失效位收紧。收紧之后，你做的是另一笔短线，却还按 swing 的目标去拿——这是周期混用。

条件单、GTC 止损在期权和盘前盘后标的上未必按你想象工作。标的在盘外跳、期权市场可能没开。隔夜风险要用仓位限制，不能只用一张白天有效的止损单自我安慰。

## 13.4.8 Swing 日志

除入场出场外，保存：

- 入场时的日线 / 周线图；
- 大盘和板块上下文；
- 持仓期间每天 thesis 是否仍成立；
- 隔夜盈亏与盘中盈亏分解；
- 计划事件与意外事件；
- 若用期权：IV、delta、theta、买卖价差；
- 最大有利 / 不利波动（MFE / MAE）；
- 退出属于目标、止损、时间止损还是 thesis 改变。

这样才能判断优势来自方向判断、隔夜跳空、盘中管理，还是偶然跟着指数吃饭。

漏记「错过的合规信号」会让人高估自己「本来能赚」。错过单独记，不进真实盈亏。

## 13.4.9 和日内共用、但数字不同的规则

- 六栏写不齐就没有这一笔；
- 止损只往有利方向移；
- 下跌不加仓；
- 过程分与盈亏分开；
- 模拟盘低估跳空、隔夜情绪和真实滑点。

不同的是：日亏损上限对 swing 要改成「账户总风险上限 + 单笔过夜风险 + 事件窗口限制」。你可能连续几天没有成交，然后在一个财报夜亏掉一周的预算。按「今天没做日内所以额度还在」去开隔夜，是错的账户日历。

## 先记住这些

- Swing 换来的是频率，付出的是隔夜和事件。
- 没有独立 thesis，就不许把日内仓改标签过夜。
- 时间止损和时间窗口必须事先写。
- 仓位按 max(技术风险, 跳空压力) 算。
- 事件前要么减仓，要么承认你在做事件。

## 不要做的事

- 把当天已经大涨的小盘当 swing 拿着。
- 因为买不起 100 股就买最便宜的虚值期权。
- 用小时图的近止损去支撑一个日线目标。
- 在财报夜指望普通止损。
- 无限延长「再等一天」。
