# 14.1 纪律与约束

> 一句话：情绪不会消失。能写进计划、能被热键和日限额挡住的，才算处理过。心理训练辅助执行，不能替代有成本后正期望的策略。

Warrior 的心理模块有一百六十小时正念和 FOMO 录音。能独立成立、不依赖现场气氛的，是一套**操作约束**：事先写死权限，用日志检查有没有改订单。本章放进计划里的硬规则；下一章放 FOMO、亏损反应和逐条练习。两者都不是励志。

若交易引发持续焦虑、抑郁、成瘾、债务或生活功能受损：停止交易，寻求当地合格专业帮助。本书不是心理治疗。

## 14.1.1 「一半技术一半心态」是比喻

课件写过 50% skill / 50% mental。提醒有价值：会认图形不等于能稳定执行。50/50 没有可测分母，不是研究结论。

更准确的关系：

```text
实际结果 = 策略质量 × 执行一致性 × 风险约束 × 市场适配
```

任一项接近零，整体崩坏。策略没有成本后正期望时，再强的纪律也只是更一致地执行负期望。策略有效但频繁违反仓位和止损，回测结果也不会出现在账户里。

所以纪律这一章的验收标准不是「我今天很平静」，而是：

- 计划外交易次数是否下降；
- 日限额是否被遵守；
- 止损是否只朝有利方向移动；
- 放大仓位是否走台阶而不是情绪。

## 14.1.2 常见失效先当成计划缺口

| 行为 | 看起来像 | 实际缺口 |
|---|---|---|
| 错过就追 | FOMO | 没有 No-trade 栏，也没有「离失效位太远就不做」 |
| 亏了加仓 | 摊平 | 没有禁止下跌加仓；全仓风险没重算 |
| 连点 | 报复 | 没有连亏暂停、没有单日上限 |
| 下移止损 | 再给一次机会 | 周期混用；失效定义被改写 |
| 盈利后加码翻倍 | 自信 | 把一笔样本当成策略已被证明 |
| 把日内仓改成隔夜 | 长期看好 | 没有独立 swing thesis |
| 照抄聊天室 | 信息优势 | 别人的成交被当成你的触发 |

意志在亏损扩大时最不可靠。约束要放在亏损发生**之前**：额度、次数、时间、平台锁。被套时先做空仓测试（下一章），不要做自我评价。

## 14.1.3 规则是护栏，不是事后惩罚

一份能让第三方复现的计划至少包括：交易目标和资本边界、股票 / 合约池、数据源、可交易时段、市场上下文、setup、触发、失效、仓位、订单类型、日 / 周风险、禁止交易条件、日志和复盘节奏、策略改版流程。「我做牛旗」「低买高卖」不可复现。

规则要同时满足：

- **客观**：能否触发，第三者看得懂；
- **即时**：触发后马上执行；
- **自动**：尽量不依赖高压时的意志；
- **可审计**：日志能证明有没有遵守；
- **与风险相关**：不是无关的自我惩罚。

「违规后去跑步五分钟」不能撤单，还可能让人隐瞒违规。更好的设计：

```text
若已实现 + 未实现盈亏 <= −X：
flatten → 撤销全部挂单 → 券商 / 平台锁定 → 当天不再实盘
```

课程列过的历史例子（日亏损上限、连亏三次停止、不做某种市值、不追第三次停牌）是讲者按自身策略写的，数值不能当你的默认。要按自己的 1R、正常连亏分布和账户可接受回撤重写。

连续三笔亏损不是万能门槛。胜率 40% 时三连亏并不罕见。可以把它写成暂停触发器：

1. 暂停 15 分钟；
2. 复核三笔是否合规；
3. 有规则违约或已到日限额，结束；
4. 全部合规且计划允许，只以缩小后的风险继续。

软暂停用来审查，硬停止不允许主观例外。

## 14.1.4 必须写进计划的硬约束

一次不要上十个习惯。选少，写死，用日志看行为有没有变。最低集合：

### 4.1 单笔与当日

```text
单笔风险 R（美元）事先固定
软暂停 = −2R（示例，需按自己的分布校准）
硬停止 = −3R
回吐止损 = max(固定金额, 当日峰值回吐比例)
开仓风险计入限额，不只看已实现
```

回吐止损（giveback stop）处理的是另一类破坏：今天已经赚到，后面用更差的 setup 把利润送回去。从**当日权益高点**起算，回吐达到阈值就结束，和有没有「还想再做一笔更好的」无关。交易层面也可以另写：浮盈回吐超过计划的某一部分就减或平，避免把一笔赢家重新变成输家。

达到日停止后，下一笔无论看起来多好，都不属于当天计划。

### 4.2 仓位与止损

- 股数 / 张数由失效价反推，不先决定数量再挤止损；
- 禁止下跌加仓；加仓只在价格按计划推进、全仓风险重算后仍不超预算；
- 止损只能朝有利方向移；
- 不在已经停牌、或点差超过阈值的标的上开新仓；
- 不把错误的日内仓改标签隔夜。

### 4.3 次数、时间、环境

- 每日最多几笔（含「开盘前 15 分钟只许做预先写好的一笔，或不做」）；
- 个人时间过滤如果要用，写成自己的统计结果，不要神化某个钟点。课程里有人用「9:33 之前不做」降低开盘噪声，那是个人样本，不是市场定律；
- 工作区：固定、安静、无关通知关闭；代码 / 账户 / 订单状态醒目；手机和社交媒体移出；清单可见；到点提醒结束；平仓后离开平台，不回来看「最后一笔」；网络、电源和备用平仓渠道已测试；
- 墙上只贴当前规则和风险上限，不贴收益截图。

### 4.4 收入目标不能反推必须交易

危险链条：

```text
今天必须赚 500 → 只赚了 200 → 再做一笔 → 降低标准 → 亏损
```

每日控制的是最大风险、最大笔数、允许的 setup、交易窗口和过程分。收入用长周期分布估算，并准备其他收入和现金缓冲。不要用借款、生活费或短期必须支出的钱交易。

## 14.1.5 过程分与盈亏分开

日评分拆开：

| 项 | 记什么 |
|---|---|
| Setup 选择 | 是否在池子里、六栏是否写全 |
| 风险计算 | 股数是否由止损反推 |
| 订单执行 | 计划价与实际均价 |
| 止损遵守 | 有没有下移、有没有撤 |
| 暂停遵守 | 该停是否停 |
| 数据记录 | 当时记还是事后编 |

盈亏单独一列，不参与当天行为分。违规后的幸运获利不算进策略样本。结果偏见（outcome bias）的修法就是这一条：过程对、钱亏了，行为分仍是满分；过程错、钱赚了，行为分是零，并记 rule_break。

身份不要绑在 P&L 上。「我是能赚钱的人」会让人拒绝止损。改成过程目标：今天每笔都先算 size。一笔亏损只证明一次结果，不证明交易者整体能力；一笔盈利也不证明已经掌握策略。

## 14.1.6 日志最小字段与利润三角

一行是一笔完整往返。和券商对账单对账，不要为了好看把 7 美元记成 10 美元。多次加仓 / 分批用成交加权，不要肉眼平均。

```text
trade_id
日期 / 时间 / 时区
代码、方向、setup、催化
入场理由
股数或张数、加权均价
初始止损、计划风险、目标
部分成交
加权出场
毛盈亏
佣金、监管费、借券费
净盈亏
MFE / MAE、滑点
followed_plan
rule_break
入场前 / 出场后截图
教训和改正动作
strategy_version
```

新增列的原则：它能回答一个你准备据此改行为的问题。否则只增加填写成本。错过的合规信号单独记，不要混进真实盈亏。

利润三角（Profit Trifecta）三个维度：

1. **Consistency**：连续不爆规则、权益曲线不乱的周数，不是「感觉很稳」；
2. **Accuracy**：盈利笔数 / 总笔数；
3. **Profit/loss ratio**：平均赢 / 平均亏的绝对值。

三条边不是三枚独立奖章。准确率高但平均亏损过大，仍可能亏。课程按分层打分，分数是诊断工具，不是放大资金的许可证。录制材料里「7 分以上很可能盈利」只是经验阈值，不是统计保证。

底层仍是期望值：

```text
期望值 = 胜率 × 平均赢 − 败率 × 平均亏 − 平均交易成本
```

定位弱项：

| 现象 | 先查 |
|---|---|
| 准确率低、盈亏比好 | 入场选择、确认、市场状态 |
| 准确率高、盈亏比差 | 摊平、晚止损、过早止盈 |
| 两者尚可但不稳 | 仓位乱变、过度交易、某类星期的违约 |
| 毛正净负 | 佣金、借券、行情费、滑点 |
| 分数提高但回撤也扩大 | 可能只是仓位变大，不是优势变好 |

## 14.1.7 放大与模拟盘的门

模拟盘能练流程，不能证明实盘可复制。它几乎必然低估：排队、部分成交、冲击成本、急速滑点、借不到股票、停牌竞价、期货强平、以及真钱的生理反应。「模拟赚了一个月」最多证明：你能在没有真实惩罚的环境里重复规则。

上线或加仓同时满足：

- 同一 setup 定义下样本足够大；
- 成本后期望值为正；
- 分 setup 看仍然有边；
- 最大回撤在预设范围；
- 没有摊平 / 止损违约；
- 加仓后仍能按同样速度退出；
- 一次只上一个小台阶；
- 跌破阈值自动退回上一档。

日历上的「先模拟三个月」是最低提醒，不是毕业。三个月可能只经历一种市场状态，也可能每天乱做却没有固定策略。

从模拟转实盘（心理课反复出现的操作）：

1. 用同一平台，减少键位意外；
2. 仓位先降到「亏损会不舒服但不够毁一周」；
3. 第一周只设过程目标：仓位对不对、亏损日怎么停、笔数有没有超；
4. 每日交易次数上限写死；
5. 真钱会把你打回旧习惯，按旧习惯的红旗直接停，不要「先适应一周再上规则」。

账户小到无法以安全仓位交易时，继续模拟或换更小的产品（例如用微型期货表达指数，而不是在股票里把止损挤近）。「小账户必须更激进才能长大」是破产叙述。

## 14.1.8 学习阶段：不要把丢规则当成专家化

课程用新手到专家的阶段模型（大意来自技能习得，不是认证量表，也没有固定学时）：

| 阶段 | 特征 | 目标 |
|---|---|---|
| 新手 | 依赖清单，分不清信息重要性，容易模仿 | 平台安全、统一语言 |
| 高级新手 | 认出重复形态，规则过多且互相冲突 | 限制池子和 setup，建立日志 |
| 胜任 | 能取舍，开始看到市场上下文 | 稳定执行、理解分布 |
| 熟练 / 专家 | 识别更快，知道何时不做 | 仍用数据防止直觉漂移 |

专家所谓直觉，通常来自大量带反馈的模式记忆。新手丢掉清单不是专家化。专家仍然会错，也不能把「感觉」豁免于风险限制。规模放大可能重新触发从前没有的压力，要按实际风险金额逐级暴露，不要从模拟直接跳到大仓。

策略改版必须版本化：盘中不改；写出假设和差异；回测或模拟；留出样本外；指定生效日；小规模前瞻；不行就回滚，而不是继续叠加例外。日志写 `strategy_version`。

## 14.1.9 外部责任与社区

可以让教练、同伴或家人：复核周日志、监督触发日停止后是否还在交易、发现规模悄悄上升、在重大生活压力时提醒暂停。对方不能替你承担损失，也不应变成跟单来源。共享时保护账户、身份和医疗隐私。

社区能用来复盘、对原始来源、发现执行盲点。风险是跟单、幸存者偏差、比较盈亏、只晒赢家、群体 FOMO、把讲师的风险容忍度当标准。延迟几秒的喊单对快速策略已经失效。任何别人提到的标的，必须通过你自己的完整清单。

不要跟单。即使代码和方向相同，入场时间、仓位占比、对方已有的浮盈缓冲、退出计划、信息时点、流动性都可能不同。别人的成交是研究线索，不是触发。

## 14.1.10 期货账户上的同一套纪律

第三章的十条改成期货语言后，核心不变：无聊的重复、保证金缓冲、不把行情私人化、过程目标。额外检查：

- 合约月份、移仓日历、报告窗口写在盘前；
- 相关品种名义合并计算；
- 日保证金使用率不是风险指标，止损美元和跳空压力才是；
- 微合约降低每跳美元，不降低乱点次数，次数上限照旧。

## 先记住这些

- 纪律是权限设计，不是性格改造。
- 日亏损、回吐、连亏暂停、禁止下跌加仓，写进平台能执行的地方。
- 过程分与盈亏分家。
- 一次只加一条约束，用日志验收。
- 模拟盘不训练亏损后的行为。

## 不要做的事

- 用「再给自己一次机会」覆盖已经触发的日限额。
- 把心理课当成可以放大仓位的理由。
- 用跑步、冥想代替 flatten。
- 复制聊天室仓位。
- 在生活压力已经占满自控资源时，仍按「正常日」交易。
