# 9.7 盘中入口

> 一句话：入口形态负责把结构转成触发；技术策略负责定义方向、目标与失效。不要把事后画出的线当作实时精确预测。

卷五的形状目录在大盘上仍然可用。本章只写大盘盘中常见、并且必须和指数、VWAP、口袋一起用的那几条入口。VWAP 的完整四种走法在第 08 章。这里先出现回踩，是因为它经常和阻力拒绝、开盘速度线叠在同一笔里。

![影线试探不是接受；实体站上才算](../assets/wick-vs-acceptance.svg)

## 9.7.1 速度线

把开盘前后的高点连成水平或斜向参考，价格跌破后又强力收回并上行——课程称之为高概率速度线。「高概率」是命名，不是已给出的统计概率。

线的锚点与最少触及次数必须预先规定，否则可在任何走势上事后贴合。真正触发是跌破、收回或回踩反应，不是线本身。开盘附近样本少、刺穿多，第一条速度线尤其容易成为 trap。

复盘时标出：当时已经固定的锚点；是跌破后做空，还是收回后做多；指数当时是否同向；收回是否在 VWAP 一侧被接受。

## 9.7.2 三角形

价格振幅收缩，上下边界逐渐靠近。入场位于离开三角形的一侧。收缩前应有语境，例如更低高点或更高低点。孤立收缩没有方向。

靠近顶点时空间小、假突破多，必须看下一结构位和口袋。突破后的接受或回踩，比单个影线更可靠。大盘三角形经常出现在开盘区间之后的中段：人人都看见要选择方向，止损又都在两边。仓位按「假突破一次仍活得下去」来配，不要按「这次一定走完口袋」来配。

## 9.7.3 阻力拒绝后的空头延续

价格在阻力附近受阻，跌破后沿趋势继续下行。空头入场可以是拒绝、跌破或回踩失败，三者风险不同。止损参考阻力上方或失败回踩的高点。下方主要支撑或口袋尽头决定目标，不能因趋势漂亮无限持有。

大盘空还要额外满足：

- 可借 / 易借状态；
- SSR；
- 分红与公司事件；
- 板块 / 指数 beta；
- 可能引发回补的催化；
- 收盘竞价；
- 若不平仓，隔夜风险。

流动性高降低一部分执行风险，新闻回补仍可显著跳空。个股在日线阻力下方、盘中又跌破 VWAP，应写成一个假说：「日线拒绝 + 盘中走弱」。两个参考都来自价格与成交路径，相关性很高，不能当作两倍胜率。止损放在 VWAP 收回还是日线位置上方，取决于交易周期。目标先看盘中低点，再看更大口袋。

## 9.7.4 VWAP 回踩（入口层）

价格跳空或冲高后回落到 VWAP 附近出现买盘反应，随后恢复。VWAP 是当日成交量加权均价，不是自然支撑。入场需要拒绝 K、更高低点或重新站上。第一次触碰未必有效。如果价格在 VWAP 下方形成接受，回踩假说失效。

开盘附近 VWAP 样本少、变化快，不能把早期数值当稳定均衡。更完整的四种 VWAP 走法、时段差异和止损设计见第 08 章。盘中入口章只要求：碰线不是触发。

## 9.7.5 入口的统一字段

不允许只写「看起来要突破」。

```text
语境：趋势 / 反转，宏观位置
形态：三角 / 回踩 / 拒绝
触发：精确价格事件
接受：N 秒或 N 根
止损：结构失效
目标：下一口袋 / 位置
最大限价：
时间退出：
指数 / 板块条件：
```

预判、确认、回踩三种执行分开统计。不能拿预判的低价与回踩的高胜率组成一个不存在的策略。大盘给你等待回踩的时间通常比小盘多；这也意味着你更常面对「不给回踩」的踏空。踏空记 skipped，不记亏损，也不因此在下一笔改成追。

| 入场 | 优点 | 缺点 |
|---|---|---|
| 预判 | 价格好、止损近 | 方向未确认 |
| 确认 | 趋势已启动 | 容易追价 |
| 回踩 | 可验证接受 | 可能不给机会 |

## 9.7.6 复盘两张图

保存入场前后各一张，并标：

- 当时已经可见的线；
- 哪些是事后新增；
- 实际成交；
- 第一次回踩；
- 是否到达 1R / 2R；
- 假突破持续多久；
- 市场 / 板块；
- 量价关系；
- 未成交或跳过的交易。

只有保留当时画面，才能判断自己是在识别结构还是解释结果。大盘图好看，事后解释的诱惑更大。

## 9.7.7 速度线的两种用法，不要事后挑

用法 A：开盘冲高后回落，跌破连线，按空处理，目标看 VWAP 或开盘区间低。  
用法 B：跌破后迅速收回并在线上接受，按多处理，目标看盘前高或下一口袋。

两者不能在同一根 K 上临时切换。开盘前写：今天这只股票若离开开盘区间，你做离开的方向，还是做假突破收回。两种都做，等于没有策略。收回那一种，接受定义必须先写死，否则第一根刺穿就会让你空完又多。

锚点至少两处已经发生的反应，而不是把当前最高点和你希望它成为速度线的点连起来。保存盘前截图。收盘后如果这条线被你挪过，这笔从样本里剔除，记成画线违规。

## 9.7.8 三角形离开之后看口袋，不看「量能突破」口号

收缩本身是波动下降。离开时量增加，只说明参与回来了，没说明能走多远。先量：

- 离开的那一侧到下一位置有没有 ≥ 1R；
- 指数有没有同步离开自己的收缩；
- 离开后是否在新侧停留满你的接受根数。

靠近顶点还没离开就进，止损往往已经小于正常点差波动，会被扫出后再看它走出口袋。那不是「差一点」，那是入场时机错了。正确动作是等离开，错过就错过，或等回踩。回踩不来，记 skipped。

## 9.7.9 大盘空头的执行顺序

```text
日线阻力或开盘区间上沿仍然有效
  → 指数没有强势新高
    → 可借确认、SSR 状态清楚
      → 出现拒绝或跌破
        → 在 VWAP 下方或刚跌破 VWAP
          → 下方口袋够 1R
            → 才下空单
```

任何一层否决就停。不要因为「阻力很漂亮」跳过借股，也不要因为「指数稍微红」就忽略个股仍在 VWAP 上接受。回补计划写在入场前：第一目标、部分回补、若收盘仍持有怎么办。大盘收盘竞价可以剧烈，隔夜不是默认选项。

## 9.7.10 入口与 VWAP 重叠时只保留一个名字

日线阻力 + 盘中 VWAP 拒绝 + 开盘区间下破，是一个空头假说，不是三个 setup。日志里只打一个主标签，其余当语境字段。否则你会在复盘时以为自己有三个高胜率工具，其实是同一笔被数了三次。

主标签怎么选：事先规定优先级，例如「有明确 VWAP 四种之一就归 VWAP，否则归阻力拒绝，否则归开盘区间」。优先级可以改，但要写进变更日志，并且旧样本不重新贴标签去美化曲线。

## 9.7.11 预判、确认、回踩在大盘上的典型代价

预判：在阻力下或 VWAP 附近提前进，止损近，假方向多。大盘给假方向的方式是 trap——刺穿你的触发，再回到原区间。预判仓位必须能扛一次刺穿后的计划失效，而不能指望「大盘滑点小所以可以满仓预判」。

确认：价格已经离开，你买离开。代价是离失效远，盈亏比变差，且更容易买在柱顶。大盘确认单若已经走出 1R 才进，通常应放弃或等回踩。

回踩：接受已经发生，价格回到原水平。大盘比小盘更常给回踩，也更常给「回踩变 trap」——回到水平后直接穿过去。回踩的失效要短：水平另一侧被接受，而不是「再等等它回来」。

三种的胜率和盈亏比不会一样。把它们拼成一个策略，是在用预判的入场价和回踩的胜率欺骗自己。

## 先记住这些

- 线的锚点事先固定，触发是反应不是线。
- 空头延续看口袋尽头，不看「还能跌多少」。
- 三种入场分桶，踏空不是惩罚。

## 不要做的事

- 在三角形顶点用满仓赌方向。
- 把 VWAP 第一次触碰当买入。
- 用指数已经走弱的个股旗形当独立优势。
