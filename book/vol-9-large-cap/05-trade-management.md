# 9.5 仓位管理与工具

> 一句话：先决定何时失效，再决定加减仓。平台、新闻和数据服务只负责可靠执行，不创造策略优势。

小盘管理的核心是停牌和薄盘退出。大盘管理的核心是：结构止损不要被噪声吓进错误位置、加仓不要在赢家上偷偷加大总风险、工具不要多到无法审计。

## 9.5.1 止损放在假说失效处

不同入场对应不同结构止损。止损应放在假说失效处，而不是按账户想亏多少钱反推任意价格。若结构止损太远，用仓位解决。把止损塞进噪声，只会提高无效止损率，然后诱使你在下一笔把止损放得更宽。

开盘跳空与快速 K 线可能让实际成交超过止损。大盘开盘区间经常先扫一侧再走另一侧。把开盘后第一根刺穿当失效，可能正是被区间噪声处理。计划里写清：开盘后前 N 分钟用更宽的结构止损、更小的仓位，还是直接不做。

止损类型在第 08 章结合 VWAP 再比较。这里先定顺序：先有失效定义，再选订单类型。停损市价不控制价格；停损限价不保证成交。

## 9.5.2 分批是一串新决策

初始入场、加仓、部分退出和最终区域，每一段都要单独记账：

```text
第一批：股数、入场
第二批：股数、入场
当前加权均价
当前止损
总开放风险
已实现盈亏
剩余目标
```

每次加仓必须重新计算总仓到止损的美元风险。只在赢家上加仓，也可能使总风险增加。提高止损不能保证跳空或快速回撤时成交。部分止盈会降低风险，但过早减仓也可能让平均盈利不足以覆盖亏损。这两种偏差要靠分 setup 的统计看，不能靠单笔感觉调。

大盘加仓还有容量问题。100 股的回踩和 3000 股的回踩不是同一个流动性事件。扩仓前按第 01 章的仓位档单独算期望值。

## 9.5.3 管理顺序

1. 入场前写失效；
2. 成交后核对真实均价；
3. 到 1R 前不因盈亏颜色移动止损；
4. 达预定位置才减仓；
5. 加仓前确保总风险仍在上限；
6. 结构失效就退出；
7. 收盘后用实际成交复盘。

第 3 条专门对付大盘磨单：价格在你成本附近来回，账户颜色一会儿绿一会儿红。颜色不是信息。信息是结构还在不在。

时间退出要写进计划。大盘同一 setup 可以磨很久。没有时间规则，你会把一笔已经死亡的突破拖成下午的噪声。

## 9.5.4 平台是执行基础设施

需要理解的是持仓、未完成订单、Level 2、成交明细、下单框的职责。录制期界面、费用和路由会过时。平台推荐有商业和地域背景，不应仅凭课程选择券商。先核查监管、资产保护、费用、行情、路由、空头可借与应急支持。

工具的最小集合：

- 受监管券商；
- 可靠的实时行情；
- 复权口径一致的图；
- 扫描器 / 名单；
- 原始新闻 / 文件入口；
- 经济日历；
- 执行端；
- 风险控制；
- 券商结单导出；
- 日志。

每个新增工具都应解决一个已识别问题。否则只增加认知负担。大盘尤其容易堆指标和新闻窗。窗口回答不了一个问题，就关掉。

## 9.5.5 新闻源

「没有新闻就不交易」对财报 / 新闻动量策略是合理过滤器；对指数 / 技术策略则需另行定义。新闻源速度不等于准确。标题后仍要核对原始稿和文件。宏观日历必须与公司新闻同时监控。

大盘的新闻风险经常不是「没有新闻」，而是「新闻已经在指数里，个股还在重复同一个标题」。计划写清你交易的是首次信息还是二次传播。

## 9.5.6 数据完整性

开盘前检查：行情是否实时；时区和交易时段；拆股 / 分红复权；图与券商报价是否一致；未平仓和未完成订单；购买力；空头 / SSR 状态；公司事件。数据错一项，精细技术分析也会失效。

大盘常见的数据坑：不同平台对是否计入盘前的 VWAP 不一致；分红日未复权；指数期货与股票图时区不同。VWAP 配置放到第 08 章逐项确认。这里只要记住：数据错了，今天的优势假设作废。

## 9.5.7 应急计划写在平台外

```text
券商交易台电话
账户识别
如何全部取消
如何用网页 / 手机平仓
备用网络
备用电源
报价冻结时做什么
故障期间允许的最大仓位
```

平台冻结时不要反复点击产生重复订单。先从另一渠道核对未完成单。大盘名义金额大，误触一次的绝对美元比小盘更吓人。券商层最大股数 / 名义限额在这里同样必要。

## 9.5.8 用数据而不是界面偏好比较工具

- 订单确认延迟；
- 相对最优报价的成交质量；
- 拒单 / 撤单；
- 可用时间；
- 行情缺口；
- 每月固定成本；
- 每股 / 每份费用；
- 导出是否完整；
- 支持响应。

真正的目标是稳定、可审计地执行交易计划。按钮教程不进本书。

## 9.5.9 加仓算术：赢家也会把风险做大

```text
第一批 200 股，入场 100.20，当时止损 99.70，开放风险 100
价格到 100.80，你加 200 股，新止损抬到 100.40
表面：新止损已高于第一批成本，好像没风险
实际：第二批到 100.40 仍亏 0.40 × 200 = 80
若快速回撤直接打到 100.10，两批一起按新止损未必成交
跳空或扫损后的均价可能远低于 100.40
```

所以「把止损抬到保本上方再加仓」不是免费许可。加完必须重算：最坏可接受成交下，总美元是否仍 ≤ 单笔上限。大盘扫损比小盘停牌温和，但开盘和数据公布时一样可以越过你的新止损。

部分止盈的另一面：第一目标就走掉 2/3，剩下 1/3 即使走到 3R，平均赢家可能只剩 0.8R。若亏损端仍是完整 1R，期望值会被自己的止盈习惯杀死。分批比例要进样本，不能只进口诀。

## 9.5.10 新闻策略和技术策略不要共用同一套工具习惯

做财报日动量，新闻源延迟三十秒就可能是整笔优势的消失。做开盘区间加 VWAP，新闻窗可以缩成日历提醒，避免标题诱发额外交易。两种策略可以存在于同一个账户，但不能存在于同一分钟的同一热键。

数据完整性出问题那天，例如图上的 VWAP 和券商报价对不上，正确动作是当天降为只平仓、不开新仓，而不是「凭感觉继续」。大盘给你的信心来自数据一致，不是来自形态熟悉。

## 9.5.11 磨单时的两套钟

大盘同一笔可以磨四十分钟。你需要两套钟：

- **结构钟**：更高低点还在不在，VWAP 关系变了没有，指数坏了没有。
- **时间钟**：预先写的最长持有。到点还没有向目标推进，减仓或退出。

只有结构钟，你会在死亡的突破里等「再给一次回踩」。只有时间钟，你会在正常回撤里被震出去。两套同时写进计划，复盘时分别统计：因结构失效走的、因时间走的、因情绪提前走的。后一种单独列违约。

到 1R 前不因颜色移动止损，针对的就是磨。账户从绿变红再变绿，不是新信息。新信息是：有没有出现你事先写的失效事实。

## 先记住这些

- 失效先于加减仓。
- 到 1R 前不要被账户颜色指挥。
- 工具为计划服务，计划不为工具服务。

## 不要做的事

- 把止损塞进噪声，再抱怨「总是扫止损」。
- 故障时连点热键。
- 为了看起来专业而增加回答不了问题的窗口。
