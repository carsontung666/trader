# 8.3 选股与名单

> 一句话：选股是第一层风险管理。把流通、催化、日线和流动性放在一起，而不是只追涨幅榜。

卷一已经写过扫描器和观察名单的通用漏斗。本章只保留小盘过程：融资循环怎么污染 float、催化怎么分级、名单为什么必须写成条件式、什么样的「没有新闻」不能冒充催化。

选股的目标不是找到「最会涨」的股票，而是找到即使判断错误，也能以计划风险完成退出的异动股票。

## 8.3.1 小盘经常走的那条公司循环

历史上不少长期亏损、持续融资的小盘走过类似路径：上市 → 货架 / 增发增加股数 → 价格下跌 → 反向拆股 → 再融资。这不是每家小盘的必然生命周期，但是一个有用的风险模型。

反向拆股机械降低发行股数后，扫描器可能显示「极低流通」。潜在权证、可转债和新发行仍会增加供给。需要沿最新文件重建充分稀释后的股数，不能只看一个第三方 float。

检查链：

1. 最新定期报告里的发行股数；
2. 最近 8-K / 招股补充；
3. 有效货架 / ATM；
4. 权证和可转债条款；
5. 反向拆股生效日；
6. 之后的后续事件；
7. 现金消耗和持续经营疑虑。

文件以监管机构当前检索系统为准，不靠标题聚合器的一句摘要。课程把货架比作「已经拔销的手榴弹」太绝对。货架是能力，不是时间承诺。但对隔夜或长时间持有，确实需要折价评估。对纯日内、收盘前必须清仓的计划，货架仍是减分项：盘中也可能出定价公告，流动性会瞬间反过来。

## 8.3.2 六层过滤，一层不合格就删

![扫描器只是漏斗顶，漏斗底不是买入](../assets/selection-funnel.svg)

### 价格与证券类型

排除不适用的场外、权证、权利或特殊单位，确认普通股或 ADS。代码相近、权证和正股不是同一证券。

### 流通与实际供给

名义 float 之外，还看持有人结构、解锁、转售登记。刚做完反向拆股、刚宣布 PIPE、刚登记转售的，扫描器数字往往滞后。

### 成交量 / 相对量

成交量必须足以支撑目标股数，且异常量发生在**当前时段**。昨天全日放量、今早已经枯竭，不算。相对量要和同一时段比，不要拿开盘十分钟去比全日均值。

### 催化

原始、当日、明确、与公司规模相关。一亿美元合同对年收入五千万的公司和年收入五十亿的公司不是同一事件。

### 日线

上方空间、长期均线、是否有过「冲高回落」记录、反向拆股复权是否可靠。日线过不去，就不必继续读新闻。

### 执行

点差、深度、停牌带、路由、借股。计划仓位在可见深度里退不出，前面五层全作废。

任一层不合格都可以删除候选。删除是选股的主要工作。

## 8.3.3 扫描器是候选生成器

多个扫描面板把缺口、动量、成交量分开，能降低全市场搜索成本。同一股票同时命中多个条件，不等于多份独立证据——字段往往高度相关：涨幅、相对量、创新高经常是同一件事的三种写法。

扫描器上的流通盘和新闻必须回到原始来源核验。报警后才打开图和 Level 2，不能在看到颜色高亮后直接下单。

开盘前更稳妥的用法是：用缺口 / 流动性选出前 5–10 只，做完下面的名单流程，而不是开盘后对着滚动榜追第一名。第一名最拥挤。拥挤带来滑点、假突破和停牌。

扫描参数本身要可复现，否则「最近不好用」无法区分市场变了、参数变了还是人变了。保存：价格区间、缺口或涨跌幅阈值、相对量和最低量、流通 / 市值范围、触发事件、时段、是否过滤 ETF / ADR / 权证、软件版本和修改日期。这些数字全部是启发式。

## 8.3.4 催化分类：先核验，再决定看不看图

### 财报

不预测报告。公布后比较实际与预期、收入和每股收益质量、指引、一次性项目、当日成交量和价格是否在新区域接受。预期差很大但价格不接受，优先信价格。

### 医药 / 临床

区分试验阶段、终点、样本量和审批阶段。公司新闻稿的「positive」不能代替完整结果。这类股票停牌和跳空更常见，仓位默认更小。

### 合同

比较合同金额与年收入、是否有约束力、执行周期、利润率、是不是只是框架协议。

### 并购

明确现金、换股、条件和交易价。价格快速靠近确定报价时，剩余上行空间可能很小。把并购套利当成动量突破，是用错工具。

### 增发

对多头通常是供给风险，但要看价格、规模、是否带权证、市场是否已经预期。不能只靠「增发 = 看空」机械做空——有时消息已经在价格里，有时借不到，有时 SSR 改执行。

### 拆股 / 反向拆股

本身不创造价值，可能改变报价、流通展示和合规状态。

### 分析师目标价

来源质量和当时关注度决定影响。孤立目标价通常弱于原始公司事件。

### 热门板块 / 同情上涨

需要本身成交量和结构确认，不因同标签就共享走势。同情股的第一波经常是最拥挤、最容易假突破的一波。

## 8.3.5 「纯技术」不是催化

没有找到新闻的异动也可能很强。这只表示当前没有可核验的基本面催化，不表示真的没有信息。可能是数据延迟、社交传播、行业联动或你没查到的文件。

无法解释的上涨会吸引空头，也会增加交易所问询、增发和快速回撤的风险。可以观察技术结构，但应降低确信、仓位和持有时间。不要把「纯技术」四个字写进催化栏。催化栏要么有来源和时间，要么写「无」。

## 8.3.6 日线是继续研究的门票

从当前价格向左看历史阻力和大 K 线。数据还没加载、复权方式不明，不能凭扫描器数字下单。课程热点（某只曾经的明星股）只是历史例子，不能成为「热门就可以忽略价格和流通盘」的永久例外。

日线要回答的是第 04 章那些问题：在历史低位、区间还是所谓蓝天；上方哪一段有大量被套成交；是否刚跑过一轮又吐回去。日线没有空间，盘中形态再标准也不进 A 级名单。

## 8.3.7 名单顺序

课程建议从缺口扫描开始。改写成可复现流程：

1. 按缺口和流动性选前 5–10；
2. 验证代码与公司行动；
3. 记录流通盘来源和日期；
4. 读原始催化；
5. 查近期融资；
6. 画盘前高 / 低、前收、日线阻力；
7. 计算第一目标之前的 R；
8. 检查 Level 2、点差、LULD；
9. 排序成 A / B / 只观察；
10. 写明确的不做条件。

A 级：催化清楚、流动性够、日线有空间、盘前结构干净、第一目标至少约 1R。  
B 级：缺一项，只允许在 A 没有触发、且仓位更小时考虑。  
只观察：结构未完成，或点差 / 停牌不可接受。  
不做：写下来，避免开盘后临时升级。

名单宜短。同时盯十几只低流通股，判断质量会下降，错代码风险会上升。

## 8.3.8 名单不写方向故事

![左边是条件，右边是故事](../assets/watchlist-card.svg)

合格写法：

```text
Above 4.80 放量 → 测盘前高 5.05
Below 4.55 → setup 失效
点差 > 0.08 或上沿 LULD 不足 1R → 不做
```

不合格写法：

```text
好公司，应该到 10 块
空头会被困住
大家都在看
```

条件式计划允许市场否定。故事会诱导持仓者忽略否定。开盘前同时写看多条件和看空条件，是为了对抗单向锚定，不是为了同一只股票两边都做。

## 8.3.9 融资风险的快速检查

- 有效的 S-3 / F-3；
- ATM 销售协议；
- 最新招股说明书补充；
- 定向增发；
- 转售登记；
- 权证行权价；
- 现金跑道；
- 股价异动后立刻融资的历史。

这一栏过不去，隔夜禁做；日内也要把「公告出现立刻退出」写成操作规则，而不是临场决定要不要「再看一眼」。

## 8.3.10 新上市和近期 IPO

初次上市交易的风险：价格发现、极宽点差、没有长历史图、流通和锁定期口径混乱、开盘竞价、停牌、借不到。近期 IPO 的突破还要看锁定期、二次出售和此前高点。

课程列出的历史暴涨 IPO 是选择性案例。失败 IPO、首日大涨后连续阴跌的样本必须一起进统计。把上市后天数当成分类字段，例如 1–5、6–20、21–60 个交易日（启发式分箱），不要把「IPO 第三天」写成可复制信号。

## 8.3.11 空头兴趣怎么用

高空头兴趣可能放大回补，但数据滞后。需要结算日、流通盘分母、回补天数、借券费用和可借量、数据日之后的公司行动。

不能把日空头成交量当成空头兴趣，也不能因为比例超过 100% 就断言违法。空头兴趣是选股的次要字段，不能单独构成做多理由。没有结构、没有量、没有催化，只剩「空头很多」，那是故事。

开盘前读得完，才叫名单。读不完，就再删。

## 先记住这些

- 一层不合格就删，删除是主业。
- 扫描器报警不是入场。
- 名单只写条件和不做，不写故事。

## 不要做的事

- 用第三方 float 替代文件核验。
- 把「没找到新闻」写成催化。
- 把扫描器第一名自动升级成 A 级。
