# 3.1 Bid、Ask 与点差

> 一句话：立刻买打 Ask，立刻卖打 Bid。报价是挂着的意愿，成交是已经发生的事实。点差是立刻成交先付的成本。

屏幕上同时出现好几种「价格」。K 线用已发生的成交画出 open / high / low / close。报价窗口用尚未成交的限价单画出 Bid 和 Ask。中间那条缝是 Spread。你点买入的时候，真正碰到的通常不是 K 线收盘价，也不是 Last，而是当时还能成交的卖单。

这一章只处理这一层：Bid、Ask、点差、报价和成交的差别，以及簿薄时均价怎样离开你看见的那一档。订单类型、热键、Level 2 多档阅读、逐笔 Tape，分别在后面几章。这里先把没有深度盘口也能成立的报价规则写死。

没有第三种报价能同时给你「立刻成交」和「不付钱」。想马上成交，就要去打对手盘，先跨过点差。想出更好的价格，就要排队，成交不再确定。后面所有订单选择，都建立在这个事实上面。

## 3.1.1 三个词先钉死

![立刻买打 Ask，立刻卖打 Bid，中间是点差](../assets/bid-ask.svg)

| 词 | 是什么 | 立刻成交时你碰到的一侧 |
|---|---|---|
| Bid | 当前公开报价里最高的买价 | 你立刻卖，打这边 |
| Ask / Offer | 当前公开报价里最低的卖价 | 你立刻买，打这边 |
| Best bid | 所有可见买价里最高的那一档 | 卖出的第一档对手盘 |
| Best ask | 所有可见卖价里最低的那一档 | 买入的第一档对手盘 |
| Inside market | 最优买价与最优卖价这一对 | 点差夹在中间 |
| Spread | ask − bid | 市价单先跨过的距离 |

Ask 和 Offer 是同一个东西。课程、平台、券商文档会混用。日志里只留一套，不要一行写 Ask、下一行写 Offer，读起来像两档价格。

Bid 不是「市场想买」。它是**当前公开挂着、价格最高的买单**。Ask 不是「市场想卖」。它是**当前公开挂着、价格最低的卖单**。两侧都可以在你的订单到达前改价、撤单、只成交一部分，或者根本不是全部真实意愿。

基本关系：

```
Quoted spread = Best ask − Best bid
```

若 Bid 10.00、Ask 10.05，quoted spread 就是 0.05。这个数先于你的方向判断存在。它不是行情软件的装饰，是立刻成交的价目表。

## 3.1.2 报价不是成交

报价（quote）和成交（trade）是两张表，不是同一件事的两种画法。

| | 报价 Bid / Ask | 成交 Last / Tape |
|---|---|---|
| 是什么 | 还没成交的限价意愿 | 已经撮合完成的交易 |
| 问的问题 | 现在立刻进出，第一档碰到哪 | 刚才真正成交在哪、多少股 |
| 会不会消失 | 会。撤单、改价、被别人先吃 | 不会。已经发生，只能被后续成交覆盖含义 |
| 数量含义 | 这一档公开显示的部分 | 这一笔实际换手的股数 |
| 常见窗口 | Level 1、Level 2、报价条 | Time & Sales、成交明细、K 线 |

挂单簿上全是限价单。买方如果愿意立刻成交，会去打 Ask，而不是在空白价位上变出一堵墙。卖方如果愿意立刻成交，会去打 Bid。留在簿上的，是还在等对手的人。

因此：

- 看见 Bid 10.00 × 500，只说明此刻公开显示有人愿意在 10.00 买、显示量 500。不证明这 500 股会等到你来卖，也不证明 10.00 下面还有人。
- 看见 Ask 10.05 × 200，只说明此刻公开显示有人愿意在 10.05 卖、显示量 200。不证明你的买单会吃到这 200 股。
- 看见 Last 10.04，只说明**已经发生过**一笔 10.04 的成交。不证明下一笔还是 10.04，也不证明你现在能按 10.04 买卖。

课程若把 Time & Sales 说成「每一张刚挂出的订单」，那是不准确的。未成交的限价单属于报价；已取消的挂单通常不会变成一笔 print。Tape 的读法在 3.4。这里只要先分开：报价是意愿，成交是事实。

一笔成交同时有买方和卖方。所谓「打在 Ask 上」或「打在 Bid 上」，是拿成交价相对当时报价的位置，推断哪一侧更主动。它不是说绿色成交「只有买没有卖」。颜色是平台编码，下一章再写；本章不要用红绿代替 Bid / Ask 这两个词。

## 3.1.3 Last、中间价、Inside market

Level 1 上最容易被当成「现价」的是 Last。它常常不是你该用来下单的那个数。

- **Last**：最近一笔已经发生的成交价。可能落在 Bid、Ask、点差内部，偶尔也会打在 Bid 下方或 Ask 上方。
- **Mid / 中间价**：`(best bid + best ask) / 2`。它是点差的几何中心，不是可成交价。没有人保证你能按中间价进出。
- **Inside market**：当前最优 Bid 与最优 Ask。立刻成交时，买碰到 Ask，卖碰到 Bid。
- **NBBO**：全美最优买价与卖价的汇总口径。许多 Level 1 报价条显示的就是这一对。它仍然看不到隐藏单、部分场所细节和即将撤销的订单。

Last 可能落后于正在变化的 Bid / Ask。快速行情里，K 线还在画上一笔，报价已经跳了两档。只按 Last 去设限价，常见结果是：你以为自己挂在「现价附近」，实际已经离开 inside market 好几档。

一个必须能口算的对照：

```
Bid 9.99 × 800
Ask 10.02 × 300
Last 10.00
中间价 10.005
```

此时：

- 立刻买，第一档对手是 10.02，不是 10.00；
- 立刻卖，第一档对手是 9.99，不是 10.00；
- 10.00 只是刚刚有人在点差里或附近成交过；
- 你的限价如果写成 10.00，既不是最优买，也吃不到当前卖。

「价格打印过 9.95」同样不等于你的挂单成交了。Print 只证明市场曾经有过 9.95 的成交。你的单可能排在别人后面，可能在其他场所，可能已经撤了，可能根本没到簿上。成交报告认 executions 窗口，不认 Last 闪过。

## 3.1.4 Level 1 先读最优价

Level 1 通常显示：

- best bid 与 bid size；
- best ask 与 ask size；
- last trade；
- 当日 high / low、volume 等附加字段。

它适合快速知道当前 inside market。读的顺序应当是：**先 Bid / Ask / 点差 / 这一档数量，再看 Last。** 把 Last 当主价格、把 Bid / Ask 当装饰，是把成交记录和报价表读反了。

课程示例里出现过 Bid 2.25、Ask 2.26，quoted spread 0.01。这只说明那一帧的最优价。不能把它当成「正常股票都是一分钱点差」。小盘热股开盘、停牌恢复、盘前盘后，点差可以是几分、一角，甚至更大。

Size 的单位必须先确认。有的平台把 `67` 显示成 67 个 round lot（约 6,700 股），有的显示实际股数，也可能因 odd-lot 展示规则不同。课程截图里的数字不能脱离平台解释。实际使用前：

1. 查平台字段文档；
2. 用模拟或极小订单观察自己的单如何显示；
3. 分清汇总 size 和分场所 size；
4. 确认刷新速度和行情订阅等级。

Bid size 不是「所有想买的人」，Ask size 也不是市场总供应。它们只是可见最优档的一部分。奇数股、隐藏量、其他场所未汇总的部分，都可能不在这个数里。

Level 1 看不到、也不能完整体现：

- 最优价后面的深度；
- 其他场所未汇总的细节；
- hidden / reserve 流动性；
- 即将取消的订单；
- 你的队列位置；
- 未来成交意愿。

所以 Level 1 不足以证明某价位「有墙」。墙是多档盘口上的候选，还要用成交去验证，那是下一章的事。本章只用 Level 1 回答一个更小的问题：立刻进出，第一脚踩在哪，点差有多宽，这一档公开量够不够你的股数。

## 3.1.5 立刻成交碰到哪一侧

方向一旦决定，碰到哪一侧就定了，不取决于你「觉得现价是多少」。

| 你要做的事 | 立刻成交时打哪一侧 | 你在点差里扮演的角色 |
|---|---|---|
| 立刻买入（开多或回补） | Ask | 主动吃卖方 |
| 立刻卖出（平多） | Bid | 主动吃买方 |
| 立刻卖空 | Bid | 主动吃买方；SSR 下普通空单可能打不到 Bid，见 3.7 |
| 在 Bid 排队买入 | Bid | 被动等待卖方来打你 |
| 在 Ask 排队卖出 | Ask | 被动等待买方来打你 |

主动跨过点差，术语上叫 taking liquidity。挂在己方一侧等待，叫 providing / adding liquidity。名字不重要。重要的是现金后果：

- 立刻买，你付 Ask；
- 立刻卖，你收 Bid；
- 两者之差，就是这一次立刻成交先付的点差。

「打 Ask」不是骂人，是描述你的买单去和卖单撮合。「Hit Bid」是描述你的卖单去和买单撮合。赢家想少付点差、输家还想挂着等更好价格，是把两种完全不同的风险混在同一份耐心里。风险已经失效时，优先离开，不为更好报价继续暴露。怎么下那张离场单，是订单类型那一章的事；**该打哪一侧**，在报价层已经决定了。

挂单簿上方看起来「稀薄」，是因为没有人在那些价位挂卖单，**不是因为没有买方**。买方如果愿意立刻成交，会去打 Ask。同样，Bid 下方空白，不是「没有卖方」，而是没有人把买单挂在更低的地方——急着卖的人会直接打 Bid。

## 3.1.6 点差怎么算，不要只看美分

Quoted spread 用美元算：

```
Spread = Best ask − Best bid
```

比较不同股价时，还要看相对点差：

```
点差% = (ask − bid) ÷ 中间价
```

0.01 的点差对 0.20 美元的股票约 5%，对 20 美元的股票约 0.05%。更细的报价增量不会自动增加可交易性。低价股上「只有一分钱」经常已经贵到吃掉计划利润。

再看三个必须能心算的对照：

| 报价 | 点差 | 中间价 | 点差% | 立刻买 100 股的第一档成本相对中间价 |
|---|---|---|---|---|
| 19.99 / 20.00 | 0.01 | 19.995 | ≈ 0.05% | 约 0.5 美元 |
| 2.25 / 2.26 | 0.01 | 2.255 | ≈ 0.44% | 约 0.5 美元 |
| 0.19 / 0.21 | 0.02 | 0.20 | 10% | 约 1 美元，且相对股价极大 |

绝对美分相同，交易含义不同。扫描器和观察名单若只过滤「点差小于 0.08」，对 3 美元股票和 0.40 美元股票仍不是同一道门槛。小盘漏斗里出现过「点差 > 0.08 不做」这类启发式，那是某一类标的、某一类止损距离的经验，不是自然常数。换成大盘、换成 0.10 的结构止损，数字必须重写。

Tick size（最小跳动）会限制点差能窄到哪里。1 美元以上的美股常见最小跳动是 0.01；更低价证券可能按更细增量报价。平台显示 10.0000 不代表你能在任意万分位成交。以券商和交易所规则为准，不要从课程界面反推。

点差还有一个容易漏掉的口径：你看见的是 **quoted spread**，账单上的是 **你实际付出去的价差**。第一档很窄，但这一档只有 50 股，你的 800 股会走到更差的价。此时「点差 0.01」只描述了屏幕最内侧那一格，没有描述你的订单。

## 3.1.7 三个必须分开的价格

![屏幕价、允许的最差价、账单均价经常不是同一个数](../assets/three-prices.svg)

- **看到的价格**：屏幕上的 last / bid / ask。它是瞬时报价，快速行情里可能已经落后。
- **允许的最差价格**：你事先写好的可接受边界。超过它，这笔单就不该按原计划继续。
- **实际成交均价**：最后填进账单、executions 窗口里的数。可能跨越多档，还要加佣金和路由费。

三者经常不一致。复盘时只看「看到的价格」会高估自己的执行。绩效只认第三栏。

看到的价格里还要再拆一次：你决策时的 Bid / Ask，和订单到达市场时的 Bid / Ask，经常已经不是同一对。日志若只抄 K 线收盘或 Last，等于把执行问题从样本里删掉。

允许的最差价格不是「心里希望」。它是一个事先写下来的数：例如买入均价不得差于 10.10，或相对当时 Ask 的滑点不得超过 0.03。市价单等于这一栏空着。空着不是更灵活，是你事先拒绝给这笔交易设边界。

实际成交均价按股数加权：

```
平均买入价 = Σ(成交价 × 股数) ÷ 总成交股数
```

部分成交时，已成交部分已经有均价，未成交部分还暴露在新的报价里。不要用第一笔 10.05 的 fill 代表整单，也不要用最后一笔最差价代表整单——两个都要记。计划入场价应是 **expected average fill**，不是 top-of-book 的 Ask。

## 3.1.8 点差是执行成本，不是方向错了

若买在 Ask、立刻卖在 Bid，即使市场价格一步都没动，你也先承担一个点差。这不是「被骗了」，这是立刻成交的价格。复盘时把这一格当成执行成本，不要把它记成「策略判断错了」。

完整成本近似：

```
总成本 ≈ 佣金 + 路由/场所费用 − rebate + spread + slippage + market impact + borrow
```

零佣金只把其中一项降为零。点差通常比零售佣金更早、更大。比较策略时使用成交报告里的实际均价，不使用图上的理想价。

先算小仓、簿还够厚、没有走下一档的情况。Bid 10.00 × 2,000，Ask 10.05 × 2,000，你买 200 股再立刻卖掉：

```
买入 200 × 10.05 = 2,010
卖出 200 × 10.00 = 2,000
点差成本 = 10 美元
合每股 0.05，合这一笔名义本金约 0.5%
```

行情没动。图表是一根十字。账户少了 10 美元。这 10 美元不是止损，不是滑点 bug，就是 quoted spread × 股数。

相对你的 1R，点差会吃掉多少，必须在进场前算：

```
点差占 1R 的比例 = spread ÷ 每股计划风险
```

课程和平顶突破的否决清单里出现过一条启发式：Spread 超过每股风险的 20% 则不做。例如风险 0.25，spread > 0.05。20% 不是物理定律。它的意思是：执行成本已经大到，胜率再好看也很难养活这套止损。你的数字可以改，不能不写。

再看目标空间。预期突破只有 10 美分，点差已经 5 美分，理论利润在进场时就被吃掉一半；再算一次离场点差，这张票面上看起来的 2R 可能实际不到 1R。预期幅度必须明显大于点差。大盘股通常不适合用几美分当目标去付几美分点差；小盘热股若点差已经接近第一阻力，正确动作是不交易，不是把目标画得更远来「配平」。

滑点和点差不要混成一个词。点差是你下单前就能从报价上读到的缝。滑点是订单到达后，相对你计划价或多出来的恶化——包括点差突然变宽、这一档被撤、扫到下一档、延迟。点差是基线；滑点是基线之外的增量。簿薄时两者会叠在一起，下一节用数字拆开。

## 3.1.9 往返一次，两侧都要付

多头的完整回合是：买打 Ask，卖打 Bid。空头的完整回合是：卖打 Bid，回补打 Ask。方向相反，点差方向相同——你都在主动一侧付钱。

只算进场点差、不算离场点差，会把期望值算高一截。保守的往返估计：

```
往返点差成本 ≈ 2 × quoted spread × 股数
```

这是「进出现在都按立刻成交、都只吃第一档、报价不变」的下界。真实数字往往更大：

- 进场已经走了下一档；
- 离场时 Bid 已经撤掉或点差拉宽；
- 部分成交后剩余仓位面对更差的报价；
- 停牌恢复后第一笔可成交价已经离开你看见的 inside market。

空头不要以为「打到 Bid 就空」更便宜。借股费是另一项。SSR 生效时普通空单还必须高于当前最优买价才能显示或执行，你可能连 Bid 都打不到。借股在 6.1，SSR 在 3.7。报价层先记住：空头离场是打 Ask，点差同样在。

画面上的浮动盈亏用什么价标记，必须搞清。有的平台用 Last，有的用 Bid（多头）/ Ask（空头）估算可实现价值。用 Last 标出来的「已经赚了 0.04」，按 Bid 卖可能只剩 0.01，再扣费用就平了。所谓保本，不保证净利润为零，还要算点差和费用。

## 3.1.10 簿薄时会发生什么

第一档够你的股数时，quoted spread 近似你的即时成本。第一档不够时，市价或可成交限价会沿对手盘一档一档吃上去（或卖下去）。这就是 walk the book。看见的 Ask 不再是你的均价。

### 例子 A：600 股，第一档只有 200

假设报价为：

- Bid：10.00 × 500 股
- Ask：10.05 × 200 股
- 下一档 Ask：10.12 × 1,000 股

你要买 600 股，并且这些可见卖单在你到达前都不撤：

```
200 × 10.05 = 2,010
400 × 10.12 = 4,048
合计 6,058
均价 = 6,058 ÷ 600 ≈ 10.0967
```

屏幕上的 Ask 是 10.05。你的均价已经接近 10.10。相对 top-of-book 多付了约 0.047 每股。这 0.047 不是行情对你「不利」，是你的股数大于第一档可见量。

立刻卖掉这 600 股、Bid 仍是 10.00 × 500：

```
500 × 10.00 = 5,000
剩余 100 股打到 Bid 下方下一档——如果下一档是 9.90，再加 990
```

进场已经离开 10.05，离场还可能离开 10.00。图上的「现价」全程几乎没动，账户已经不是一个点差的事。

同一张簿，三种常见结果：

| 你怎么约束 | 可能发生的事 |
|---|---|
| 不设价格边界的市价买 600 | 先 200 @ 10.05，剩余往 10.12 或更高 |
| 限价 10.05 买 600 | 最多在 10.05 或更低成交，剩余 400 可能不成交 |
| 限价 10.08 买 600 | 也无法保证成交：10.05 的 200 可能在你到达前消失；10.08 上面本来就没有显示的卖单 |

10.05 的卖单消失，不是系统故障。报价本来就可以撤。你看见 200 股，只是那一帧的公开部分。

### 例子 B：5,000 股，先估理论均价

买入 5,000 股前，先把可见卖档加总：

```
ask 5.00: 800
ask 5.01: 1,200
ask 5.03: 2,000
ask 5.06: 1,000
```

若全部可见且不撤单，理论 VWAP：

```
(800×5.00 + 1200×5.01 + 2000×5.03 + 1000×5.06) / 5000
= (4,000 + 6,012 + 10,060 + 5,060) / 5000
= 25,132 / 5000
= 5.0264
```

你看见的 Ask 是 5.00。理论均价已经是 5.0264。真实结果还受其他买单、隐藏流动性和更新延迟影响。可见档加起来不够你的股数时，不设边界的买单会继续往更差的价格走；设了限价会在限价处停下，剩下的不成交。两种结果都要在进场前算过，不能进场后再惊讶。

每笔应记录 planned price、average fill 和 worst fill。图上的 trigger price 不是绩效入场价。

### 例子 C：显示量在你到达前没了

报价仍是 Ask 10.05 × 200。你发 200 股的可成交买单，以为刚好吃干净第一档。订单在途时这 200 股被别人吃掉或撤走。你的单到达后，第一档已经变成 10.12，或者点差直接拉成 10.00 / 10.20。

这就是「画面上的 Bid / Ask 也可能在指令到达前改变」。小盘股上几秒内可以发生。仓位越大，你自己越可能是把点差打宽的那个人。

Walk 的成本可以单独记一笔：

```
Walk 成本 = 实际均价 − 下单时的 best ask（买单）
         或 下单时的 best bid − 实际均价（卖单）
```

Quoted spread 是第一档的缝。Walk 是股数压过第一档之后多付的钱。两者相加，才接近这一次主动成交的执行成本。隐藏单偶尔会让实际均价**好于**可见档加总，那是运气或未显示的流动性，不能写进计划当期望。计划按可见档不够用、会走差来做；改善记为意外，不记为技能。

## 3.1.11 点差会突然变宽

小盘股的点差可以在几秒内拉宽。点差宽 = 立刻成交的成本高。仓位越大，还可能扫到下一档，实际成本更高。

常见变宽的位置，不是神秘庄家开关，是流动性暂时离开公开簿：

| 情境 | 报价上常见的样子 | 执行含义 |
|---|---|---|
| 开盘前后几分钟 | 第一档量小，Bid / Ask 跳动快 | 图上突破很漂亮，实际 fill 可能差一截 |
| 盘前盘后 | 量低、点差宽，许多券商只接受限价 | 盘前高低要画成区域，不要当成常规时段的同一套执行 |
| 新闻刚出来 | 报价闪、Last 落后 | 你看见的 inside market 可能已经过期 |
| 停牌刚恢复 | Bid / Ask 可能短暂离开，再重新形成 | 停牌前的点差和止损价都不在了 |
| 午后流动性下降 | 点差从 0.02 变成 0.08，墙变薄 | 早上可做的 size，下午可能退不出 |
| 你自己的大单 | 吃完一档后下一档很远 | 你是把点差打宽的人 |
| 跌破关键位时 Bid 撤单 | 卖一还在，买一突然变远 | 离场成本在最需要离场时变差 |

开盘头两分钟 K 线还没形成稳定高低点，点差往往同时最宽。把「开盘就市价追」当成默认动作，是同时放弃结构止损和报价边界。午后 alert 可以看，但要重新量点差，不能沿用早盘那一格。

点差变宽本身可以当否决条件。计划里写「spread 变成 0.12，我没有交易」，是条件式计划，不是胆小。故事会诱导持仓者忽略否定：「既然要涨，宽点差也可以先冲。」观察名单上出现这类句子，就重写。写不成「点差宽于 X 则放弃」，这只股票今天对你不可执行。

已持仓时点差突然拉宽，风险计划必须已经写过：是减仓、是打 Bid 离场，还是承认此时没有可接受的退出价、仓位本就该更小。不能到这一秒才发明规则。停牌期间普通订单无法按停牌前的 Bid / Ask 成交——那是 3.6 的机制；本章只要记住：停牌后重新出现的报价，是一张新表。

## 3.1.12 显示数量不是全部意愿

公开限价单可以：

- 立即取消；
- 改价；
- 只显示一部分；
- 被其他订单抢先成交；
- 在不同场所重复或聚合显示。

所以「Ask 有 50,000 股，因此绝不可能突破」不成立；「Bid 有大墙，因此安全」也不成立。Level 1 上的 size 更加只是最优档的公开切片。

隐藏 / 储备单会让 Tape 上的成交量远大于你看见的 Ask size，价格却暂时卡住。那是下一章对照 Level 2 与 Tape 的观察，不是本章能从 Level 1 读出来的结论。本章能下的结论只有更窄的一句：**看见的数量 ≤ 可能存在的数量，也 ≥ 你真正吃得到的数量。** 两个方向都不保证。

Odd lot（不足一个 round lot 的零股）未必进入你看到的最优报价。你的 80 股和别人的 8,000 股，在同一档上的可见性可能不同。不要假设自己的小单一定显示在 Level 1 里，也不要假设看不见的零股不存在。

行情订阅等级会改变你看见的点差。延迟行情、汇总行情与付费深度行情不是同一张表。模拟盘若用不同的数据源，会系统性低估实盘点差。转实盘前要验证：模拟是否真实模拟点差、滑点、部分成交和行情延迟。

## 3.1.13 什么时候点差不可接受

「不交易」是一个需要事前定义的动作。点差是最干净的过滤器之一，因为它在下单前就能读到，不需要事后解释。

进场前至少问四句：

1. **绝对点差**相对这只股票、这一时段，是否已经宽过你验证过的阈值？
2. **相对点差**有没有把股价很低的名字伪装成「只有几分钱」？
3. **点差 / 每股风险**有没有吃掉 1R 的过大比例？
4. **点差 / 到第一目标的空间**有没有让这笔即使做对也只剩费用？

小盘观察名单里用过这类条件式写法（启发式，数字可改）：

```
No trade if spread > 0.08
或 spread > 0.20 × 每股计划风险
或 到下一阻力的空间 < 2 × (每股风险 + 点差预算)
或 可见 Ask 量 < 计划股数，且下一档已经不可接受
```

高 RVOL 但 wide spread 的标的仍可能差。扫描器排名第一，只说明符合扫描条件，不说明点差可执行。第二名到第五名里，往往才有能写条件式计划的对象。

心理价位必须和当前点差比较。Spread 已经接近 0.20 美元，精确到一两美分的水平线没有实际执行意义。支撑阻力要画成区域，宽度至少考虑点差和典型波动。小盘影线经常是点差，不是拒绝。图上的最低价不一定是现实可买到的价格——下跌过程中点差常扩大，Last 可以打在已经变远的 Bid 上。

仓位公式在卷四。这里只留和报价有关的硬约束：流动性允许的股数，不能大到计划止损时退不出。看每分钟成交量、买卖盘深度、点差、预期止损时有没有人接、自己的订单会不会显著推动价格。低量股票用理论上算得出的超大 size，是把表格里的利润当成可实现利润。点差突然变宽就放弃；放弃之后股数必须是零，不是「先买一点看看」。

## 3.1.14 复盘只认报价和均价，不认感觉

执行日志至少应能回放这几格：

| 字段 | 记什么 | 用来回答 |
|---|---|---|
| 决策时 Bid / Ask / size | 你按下之前屏幕上的一对 | 当时点差可不可接受 |
| 发送时 Bid / Ask | 若能从回报里看到 | 报价有没有在途中变 |
| 计划价 | expected average fill，不是 Last | 你事先允许什么 |
| 实际均价、最差一笔、成交股数 | executions | 绩效 |
| Quoted spread | ask − bid | 基线成本 |
| Walk 成本 | 均价相对当时 best ask / bid | 股数有没有压过第一档 |
| 是否部分成交 | 是 / 否，剩余多少 | 有没有把一笔做成两笔风险 |
| 点差是否在持仓中途变宽 | 是 / 否，变到多少 | 离场环境还在不在 |

不要把「买完立刻浮亏一个点差」记成方向错误。先标 execution。方向对错看价格随后有没有按计划走；执行对错看均价相对当时报价是否可接受。两本账混在一起，你会改策略去修下单问题，或改热键去修选股问题。

模拟盘能练读报价，不能证明实盘点差可复制。它通常低估：点差突然变宽、排队不成交、部分成交、停牌、你自己的单把簿打薄。模拟赚钱而实盘第一档总是没了，优先怀疑数据与仓位，不要先怀疑「心态」。

官方基础说明见 [SEC：Trading Basics](https://www.sec.gov/file/trading101basicspdf)。券商对盘前盘后、暂停和可见报价的处理可能不同。上线前用自己的券商文档核对，不要假设课程界面里的 Bid / Ask 字段是通用法。

本节的核心没有第三种状态：**报价是意愿，成交是事实；立刻成交先付点差；簿薄时均价离开你看见的那一档。**

## 先记住这些

- 立刻买打 Ask，立刻卖打 Bid。Offer 就是 Ask。
- 报价是挂着的限价意愿，不是已经完成的交易。Last 是成交，不是 inside market。
- Quoted spread = best ask − best bid。相对点差用中间价去除，不要只看美分。
- 买在 Ask、立刻卖在 Bid，行情不动也先付一个点差。这是执行成本，不是策略看错。
- 三个价格分开记：看到的 / 允许的最差 / 实际成交均价。绩效只认第三栏。
- Level 1 只给最优档。Size 先确认单位。看见的数量不是全部意愿。
- 第一档不够你的股数，均价会沿簿走差。先加总可见档，再决定 size。
- 点差会在开盘、盘外、新闻、停牌恢复和你自己的大单之后突然变宽。宽过阈值就没有交易。
- 往返两侧都要付。空头离场打 Ask。画面上的浮动盈亏可能用 Last 标记，可实现价值按 Bid / Ask。

## 不要做的事

- 按 Last 或 K 线收盘价当可成交价，去设限价或算盈亏。
- 在点差已经很宽、或点差占 1R 过大的名字上习惯性立刻成交。
- 看见 Last 打印过自己的价格，就以为自己成交了。
- 把 Level 1 上的 size 当成全部真实买卖意愿，或当成不会撤的墙。
- 第一档只有 200 股却按 10.05 计划 600 股的均价。
- 只记进场点差，不记离场点差；用零佣金证明交易成本为零。
- 把「买完立刻亏一个点差」复盘成方向错误。
- 用课程里的固定 0.01、0.08、20% 套所有标的、所有时段，数字从不校准。
- 点差已经拉宽还把支撑阻力画成一根精确到一分钱的线。
- 模拟盘用另一套行情，直接假设实盘点差一样窄。
