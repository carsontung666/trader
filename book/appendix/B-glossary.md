# 附录 B 术语表

只收正文用到的。中英对照，定义按本书用法。

| 词 | 本书里的意思 |
|---|---|
| Ask | 当前最低卖价。立刻买，通常打这边。 |
| Bid | 当前最高买价。立刻卖，通常打这边。 |
| Bull flag | 旗杆上涨 + 缩量旗面。触发在旗面上沿。 |
| Cover | 买回股票，平掉空头。 |
| Delta / Gamma / Theta / Vega | 期权价格对标的、delta 变化、时间、IV 的近似灵敏度。 |
| ETB / HTB | Easy / Hard to Borrow。难借通常要先 locate。 |
| Expiration | 期权到期日。产品最后交易与结算规则可能不同。 |
| First Green Day | 曾 in-play、随后多日回落，再突破前一日高点的研究假设；不是已验证策略。 |
| Flat top | 同一上沿多次未破 + 低点抬高。 |
| Float | 大致可交易股份。低流通是双向尾部，不是优势。 |
| Gap and Go | 有催化的高开，用盘前/开盘结构做触发，不是追涨幅。 |
| Halt / LULD | 交易暂停。LULD 用价格带限制极端成交。暂停期间普通止损无效。 |
| HOD | High of Day，当天截至目前的最高价，会更新。 |
| IV | 隐含波动率。从期权价格倒推的波动假设。 |
| Locate | 做空前券商对「能借到并交割」的确认。 |
| Long / Short | 先买后卖 / 借入先卖再买回。 |
| No-trade | 计划里预先写明的放弃条件。 |
| PDT | 旧的 Pattern Day Trader 框架。2026 年起被盘中保证金替代中。 |
| Premium | 期权权利金。 |
| R | 该笔计划风险。2R 表示目标距离约为止损距离的两倍。 |
| Red-to-Green | 先跌破前收盘，再站回去。 |
| RVOL | 相对成交量，和该股平时同时段比。 |
| Spread | Ask − Bid。也指期权价差策略，看上下文。 |
| SSR | Rule 201 空头价格限制，不是禁止做空。 |
| Strike | 期权行权价。 |
| Tape / Time & Sales | 已成交明细。 |
| Trigger | 预先定义的入场价格行为。 |
| Invalidation | 判断被证伪的价格/事实。 |
| VWAP | 量权平均价。位置，不是形状。 |
| Vertical | 同一到期、不同行权价的期权价差。 |
| 接受成交 | 价格在线的一侧留下实体，回落不把线还回去。对比影线试探。 |
| 尾部风险 | 计划止损覆盖不了的跳空、停牌、无流动性。 |
| 形状 / 位置 | 怎么画线 / 线画在哪。Setup 是两者的乘积。 |
