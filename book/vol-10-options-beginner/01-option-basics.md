# 10.2 合约

> 一句话：买方付权利金买权利；卖方收权利金、承担被指派时的义务。

## 10.2.1 Call 和 Put 到底买了什么

期权买方支付权利金，取得在规定期限内按行权价交易标的资产的权利；卖方收取权利金，承担被指派时履约的义务。

| 合约 | 买方取得的权利 | 买方通常希望 |
|---|---|---|
| Call | 按行权价买入标的 | 标的上涨 |
| Put | 按行权价卖出标的 | 标的下跌 |

类比只帮助理解权利和义务，不能替代合约规格：

- 房屋例子对应 Call：先付一笔订金，锁定未来的买入价。房价涨过锁定价，你仍按旧价买；房价跌了，你可以放弃，损失订金。
- 汽车例子对应 Put：先付一笔费用，锁定未来的卖出价。车价跌了，你仍按锁定价卖出；车价涨了，你可以不行使这份权利。

真实股票期权还涉及合约乘数、结算、除息、提前行权和券商处理规则。买方可以放弃不利的行权选择，卖方没有同等的单方面放弃权。

每份合约至少要看四项：

1. 标的资产（Underlying）；
2. Call 或 Put；
3. 行权价（Strike）；
4. 到期日（Expiration）。

权利金（Premium）是取得这份权利所付的市场价格。报价通常按「每股」报。标准美股股票期权常见乘数为 100，因此报价 3.90 的名义权利金通常是 \(3.90 \times 100 = 390\) 美元。公司行动后可能出现调整合约，不能在任何合约上机械假设乘数一定为 100。

一份具体合约必须同时读这四项再乘乘数。少读一项，后面所有「一张亏多少」都会错一个数量级。

## 10.2.2 标的价格如何影响 Call 和 Put

先在「其他因素不变」的条件下理解方向：

- 标的上涨，Long Call 通常受益，Long Put 通常受损；
- 标的下跌，Long Put 通常受益，Long Call 通常受损；
- Short Call 与 Long Call 的合约损益方向相反；
- Short Put 与 Long Put 的合约损益方向相反。

「卖 Call = 看跌」过于简化。Covered Call 的卖方可能仍然长期看涨，只是不认为短期会大涨。他愿意用一部分未来上涨空间，换现在确定收到的权利金。

「卖 Put = 看涨」也应理解为：愿意在较低价格接货，或认为价格不会大跌到让这笔权利金不够用。它不是「保证股价上涨」的证明。

实际期权价格不只由股价决定。即使方向看对，也可能因为时间流逝、隐含波动率下降或买卖价差而亏损。方向对了仍可能亏：标的必须在足够时间内移动足够幅度，覆盖权利金、点差和费用。

## 10.2.3 期权链怎么读

期权链（Option Chain）把同一标的的不同到期日、行权价、Call 和 Put 排在一起。它不是一张「推荐表」，只是把可交易合约摊开。

最先定位：

1. 标的代码和当前股价；
2. 到期日；
3. 中间附近的行权价（通常最接近现价）；
4. 左右两侧的 Call / Put；
5. Bid、Ask 和可成交数量；
6. 成交量、未平仓量和隐含波动率。

常见布局是：中间列是行权价，一侧为 Call，一侧为 Put。具体左右以你的平台为准，不要依赖颜色或左右习惯。

报价怎么理解：

- Bid 是市场当前较高的买价，Ask 是较低的卖价。
- 立刻买入通常更接近 Ask，立刻卖出通常更接近 Bid。
- 中间价（Mid）是参考，不是成交保证。两侧报价陈旧或数量很小时，Mid 可能完全不可成交。
- Last 可能是很久以前的成交，不能当现价。
- 报价乘以合约乘数才是实际权利金。
- 成交量大不必然代表此刻容易成交，还要看 Bid–Ask Spread、盘口数量和未平仓量。

下单前不要只按「标的—策略—到期—行权价」四步机械点击，还要确认：

- 买入还是卖出；
- 开仓还是平仓；
- 合约数量与乘数；
- 限价和预估总金额；
- 最大亏损与购买力占用；
- 到期、自动行权和被指派风险。

学习阶段不要为了速度关掉确认窗口。一旦点错到期日或张数，杠杆会迅速放大错误。

## 10.2.4 买方和卖方：四种开平仓动作

开仓和平仓动作有四种。选错会建立相反的新义务。

| 动作 | 含义 |
|---|---|
| Buy to Open | 买入并建立多头期权 |
| Sell to Close | 卖出已有多头期权以平仓 |
| Sell to Open | 卖出并建立空头期权 |
| Buy to Close | 买回空头期权以平仓 |

「卖出已有期权」是平掉 Long；「在没有 Long 的情况下卖出开仓」才是建立 Short。Short Option 也不是先借入合约再卖出，不能照搬股票做空的理解。你卖出的是一份义务，清算所会匹配买方。

买方支付权利金，卖方收取权利金，但卖方收钱并不等于已经获利。卖方利润上限通常是收到的权利金，风险取决于具体头寸。

「期权卖方亏损无限」只准确适用于某些结构，例如裸卖 Call。Cash-Secured Put 的最大亏损很大但有界（标的跌到零）。价差策略的风险也可能被另一条腿限定。Covered Call 的 Call 有股票覆盖，上涨时能交付，下跌时股票仍会亏。

合约到期损益在手续费前近似是多空双方之间的转移，但实际交易还存在佣金、价差、滑点和税费，不能把「零和」误解成买卖双方胜率必然各为一半。胜率、赔率、期望值是三个不同指标。

## 10.2.5 ITM、ATM、OTM

这三个词描述的是行权价与当前标的价格的关系，不是这笔交易最终是否赚钱。

| 类型 | Call | Put |
|---|---|---|
| ITM（价内） | 股价 > 行权价 | 股价 < 行权价 |
| ATM（平价附近） | 股价约等于行权价 | 股价约等于行权价 |
| OTM（价外） | 股价 < 行权价 | 股价 > 行权价 |

内在价值：

```text
Call 内在价值 = max(股价 − 行权价, 0)
Put  内在价值 = max(行权价 − 股价, 0)
```

几个必须立刻纠正的误解：

- OTM 不等于「没有价格」，只表示当下内在价值为零。它仍可能有时间价值。
- ITM 也不等于这笔交易盈利。花 10 美元买入一个内在价值只有 6 美元的期权，整体仍可能亏损。
- ATM 在现实中通常指最接近当前股价的行权价，不要求完全相等。
- ITM/OTM 只比较现价与行权价。到期盈亏还要加减权利金。

举例。股价 146.87 美元，140 Put 的行权价低于股价，这是 OTM Put：现在立刻行权没有内在价值，但合约仍可能值 1 美元以上。那 1 美元全是外在价值。

## 10.2.6 用数字把一张单算清楚

假设标准乘数 100，忽略费用。买入一张 AAPL 230 Call，权利金 2.25：

```text
名义权利金 = 2.25 × 100 = 225 美元
到期盈亏平衡 = 230 + 2.25 = 232.25
```

若到期标的到 240：

```text
内在价值 = 240 − 230 = 10
每股净利 = 10 − 2.25 = 7.75
一张合约 ≈ 775 美元（未计费用）
```

这是到期 payoff，不是持仓期间的实时盈亏公式。到期前还有外在价值、隐含波动率和时间。标的到 231 时这张 Call 已经 ITM，整笔交易在到期时仍然亏损。

较少权利金可以对较大名义金额产生暴露，所以百分比收益会被放大。同样的杠杆也放大百分比损失；Long Option 可以在到期前变得接近 0。挑成功区间的峰值回报当可重复结果，是课程截图里最常见的偏差。

## 10.2.7 「低风险高回报」的边界

Long Option 的**每张最大损失有限**，但若把账户大比例投入权利金，账户损失仍可很大。还要补上这些限制：

- OTM 期权完全归零的概率更高；
- Put 不需要像做空股票那样去 Locate，但需要足够的期权流动性；
- 宽点差可能让图上的收益无法成交；
- 停牌会同时影响标的和期权；
- 到期前可能被券商风控处理；
- Short Option 的风险结构完全不同，可能超过所收权利金。

起步资金、模拟盘金额、某位讲师录制期说的「1000–3000 美元开户」，都不是合适性标准。账户是否足够取决于：每笔最大亏损、权利金 × 乘数、点差和佣金、连续损失、是否需要行权资金、券商期权权限、生活资金是否隔离。若只能靠单笔投入账户 20%–50% 才让利润「有意义」，说明产品或规模与账户不匹配。

## 10.2.8 一张单的最小核对表

在交易界面确认：

- [ ] 标的代码正确；
- [ ] Call / Put 正确；
- [ ] 到期日正确；
- [ ] 行权价正确；
- [ ] Buy / Sell 和 Open / Close 正确；
- [ ] 合约数量及乘数正确；
- [ ] 使用限价并检查 Bid–Ask Spread；
- [ ] 知道最大亏损和到期处理；
- [ ] 不把 ITM 当作「已经盈利」；
- [ ] 不把收到权利金当作「低风险收益」；
- [ ] 美式还是欧式、实物还是现金结算已经核对。

## 先记住这些

- 买方买的是权利，卖方卖的是义务。
- 报价乘乘数才是现金；乘数不必永远是 100。
- ITM 不是盈利，OTM 不是没价值。
- 卖 Call 不等于看跌，卖 Put 不等于无条件看涨。
- 方向对了仍可能亏。
