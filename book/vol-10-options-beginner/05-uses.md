# 10.6 用途

> 一句话：先决定要限制下行、用有限成本表达方向，还是愿意承担义务换权利金；再选结构。先有正股论点，再选合约。

期权常见的三类用途不是三种「更高级的股票」，而是三种完全不同的收益形状。任何情况下，先比较整个组合的最大亏损，再看收到或支付的权利金。

| 目标 | 常见结构 | 主要代价 |
|---|---|---|
| 限制已有股票下行 | Protective Put | 持续支付权利金 |
| 用有限成本表达强方向 | Long Call / Long Put | 时间损耗、IV 与归零风险 |
| 愿意承担义务换取权利金 | Cash-Secured Put / Covered Call | 尾部风险或上行被封顶 |

## 10.6.1 Protective Put：给持仓限定下行

持有股票并买入 Put：

```text
Protective Put = Long Stock + Long Put
```

到期时，Put 把股票最低卖出价锁定在行权价，但保险不是免费的。

```text
保护后的最低组合价值 ≈ Put 行权价 − Put 权利金
```

设买股价 \(S_0\)、Put Strike \(K\)、权利金 \(p\)：

- 到期最低组合价值：\(100K\)（乘数 100 时）；
- 最大亏损：\(100(S_0-K+p)\)；
- 盈亏平衡点：\(S_0+p\)；
- 上涨收益保留，但需先赚回权利金。

一张指数 Put 对冲较大的股票组合时，Put 在市场下跌时上涨，减小组合的短期回撤。市场反弹后 Put 最终亏损，不代表保险「失败」；评价应看整个组合是否实现风险目标。一张 SPY Put 的 Delta 和名义金额未必正好匹配组合，不能只凭「买一张」判断对冲比例。

对冲前应写清楚：

- 要保护哪个标的或哪个组合；
- 保护多长时间；
- 能接受多少免赔区间（现价到 Put Strike 这一段）；
- 愿意支付多少权利金；
- 下跌发生后何时兑现 Put；
- 市场反弹时何时取消保险。

不要把一个月权利金简单年化为 12 倍后断言保险是否划算。Protective Put 的价值取决于尾部损失容忍度、事件窗口、相关性和替代减仓成本。直接减仓没有 IV Crush，也没有指派复杂度。

## 10.6.2 Long Option 的杠杆

Long Call 用较小权利金取得对上涨的非线性暴露，百分比回报可能远大于股票。但杠杆来自更高的损失速度和归零风险，不是免费收益。

较小期权成本可以对应较大的标的名义价值。期权涨幅远高于股票涨幅，不能简单解释为固定「28 倍杠杆」。实际敏感度会随 Delta、Gamma、剩余期限和 IV 变化。百分比收益很高的另一面，是权利金可能在短时间内损失大部分或全部。

短期方向交易至少要限制：

- 总权利金占账户比例；
- 到期距离；
- Bid–Ask Spread；
- 事件后 IV Crush；
- 计划持有时间；
- 最大允许亏损。

没有这些约束时，应先用模拟盘，而不是把真实亏损当学费。「最多只亏权利金」仍可能是账户的很大一部分，所以张数必须按风险预算算，不能按「一张看起来不贵」买。

Long Put 在难借的股票上可以表达看跌，不必去 Locate。这不等于低风险：你仍然需要期权流动性，停牌会同时冻住标的和期权，宽点差可能让图上的收益无法成交。

## 10.6.3 Short Put：收权利金并承担接货义务

卖出 Put 后：

- 最大收益是收到的权利金；
- 盈亏平衡点为 \(K-p\)；
- 到期股价低于行权价时可能被指派买入股票；
- 股价跌到 0 时损失接近 \(K-p\)，再乘合约乘数。

![Short Put 右侧封顶、左侧通往零](../assets/short-put.svg)

Long Call 和 Short Put 都可表达看涨，但收益结构完全不同。Long Call 需要较大上涨覆盖权利金，收益上限高。Short Put 在横盘、小涨或有限下跌时也可能盈利，但上行收益被锁定在权利金。「胜率更高」必须连同尾部亏损一起评估。

假设股价 147，卖出 145 Put 收 3：

```text
最大收益 = 3 × 100 = 300 美元
盈亏平衡 = 145 − 3 = 142 美元
最坏到期损失 = (145 − 3) × 100 = 14,200 美元
```

300 美元收入对应的是承担最多约 14,200 美元风险和接货义务，不能类比为无风险「租金」。

更低的 Put 行权价通常更远 OTM，收到的权利金也更少。到期不被指派的概率可能提高，但风险并没有消失。极端下跌时，多个「高胜率」月份的权利金可能被一次亏损抵消。把单月 2% 直接乘 12 年化为 24%，忽略了复利、空仓期、亏损月和保证金变化，不应作为收益承诺。

Cash-Secured Put 要求按可能接货的全部现金预留。券商允许用保证金卖出，不等于你的经济损失只等于保证金。第 06 章展开。

## 10.6.4 收权利金不是固定现金流

Short Option 的盈亏来源包括：

- 标的价格变化；
- Theta；
- 隐含波动率变化；
- Gamma 在临近到期时带来的敏感度跳升；
- 提前指派和到期处理；
- 保证金与被迫减仓。

因此应使用「风险预算下的权利金收入」，而不是「稳定租金」思维。Premium 小不等于风险小。收 50 美元可能对应数千或数万美元名义。概率高不等于期望值好。多次小额收权利金可能被一次跳空抹去。能随时平仓不等于总能便宜平仓：新闻、停牌和宽点差会改变退出成本。

每个 Short Option 仓都应先写：最大盈利、最大亏损、盈亏平衡、指派后仓位、应急退出。

## 10.6.5 Warrior 叠加：先有正股论点，再选合约

Options 系列到这里已经能说明三类用途。Warrior 的期权课和 Swing 期权课多出来的，是一套从股票图表出发的流程。它不替换上面的定义，只规定：**合约是论点的表达，不是论点的来源。**

### 5.1 正股先给四件事

股票图先给出：

- **形状**：旗面、平顶、整理、趋势延续；
- **位置**：前收、均线、水平区、整数关口；
- **触发**：价格穿过你预先画的线；
- **失效**：那根线被反向打穿，论点作废。

还要估计：这个论点需要多久兑现。1 分钟 / 5 分钟图对应极短的日内；60 分钟对应数小时到数日；日线对应 swing。期权到期日必须比论点所需时间留余量。用当周到期去交易尚未成熟的日线形态，会让 Theta 在论点验证前耗尽权利金。

均线、趋势线、枢轴是语境，不是触碰即买。不要因为期权已经亏损，就不断换更慢的均线当新止损。

### 5.2 观察名单在开盘前写完

每天追扫描器和聊天室热股，会把分析压缩到开盘后几分钟。更稳的做法是维护一份核心名单：宽基指数看市场方向，行业 ETF 看相对强弱，个股才是绝大多数交易机会。一只科技股的看跌形态，若纳斯达克和对应行业正在走强，做空论点需要更高门槛。

收盘后的准备可以压成：

```text
扫描核心名单
标出日线 / 60 分钟位置
识别正在形成的形态
记下财报和事件
写出看涨 / 看跌情景
估计需要的时间
选出候选到期区间
开盘后再看当时的期权链和流动性
```

几天没有机会是正常的。名单的价值是培养耐心，不是保证每天从列表里选一笔。每个名字必须回答：它为何符合策略、期权日均成交和未平仓是否够、点差、是否有即将到来的财报或分红、你知道哪个周期和哪条线、多久未提供机会后删除。名单太大时，收盘分析流于表面，反而回到临时追逐。

本卷不讨论加密货币。股指期货的隔夜价格可以补充风险偏好语境，连续合约代码依行情软件定义，不是下单代码。

### 5.3 合约选择从论点反推

正股 setup 尚未触发时，权利金再便宜也不应先买。顺序是：

```text
正股触发、失效、目标、预计所需时间
  → 到期日盖住窗口，并留假启动和退出流动性
    → Call 或 Put
      → 行权价：比较触达概率、Delta、外在价值、点差占比、IV、最大权利金、到期盈亏平衡
        → 限价、张数、最大亏损
```

课程偏好「略微价外、可合理跨越的行权价」，理由是资金小、百分比回报高。这是讲师风格，不是普遍最优。同一股票移动下，ITM 合约 Delta 更高、价值保留通常更好；OTM 的峰值回报更高，部分来自初始权利金很小。远 OTM 彩票式合约不应因单价低就买更多。

到期日：

- 更近：权利金较低，Theta / Gamma 更剧烈，时间容错低，到期操作更近。
- 更远：权利金更高，Theta 通常较缓，对 IV 更敏感，给论点更多时间。

从论点持续时间反推：

```text
预计移动窗口
+ 假启动的时间
+ 带流动性退出的时间
= 实际需要的最少到期天数
```

### 5.4 止损、目标和张数

视频里出现过权利金止损 10%–50%、目标 30%–150%、追求 3:1 这类数字。不能固定套用：

- 正股结构不同；
- 近到期权利金的自然波动可能超过 10%；
- 宽点差本身可能占 10%；
- IV 变化会让权利金止损在正股尚未失效时触发；
- 跳空可能造成 100% 权利金损失。

更稳妥：

```text
正股失效
  → 估计该情景下期权值多少
    → 加点差 / 滑点
      → 用最大美元风险反推张数
```

```text
张数 = floor(最大美元风险 / 止损情景下每张估计亏损)
```

若最坏情况是权利金全损，再检查：

```text
已付权利金 × 乘数 × 张数
```

是否在账户允许范围。单笔拿账户 10% 去冒险属于非常高风险，即便技术熟练也可能连续几笔摧毁账户。初学者每笔 1%–3% 是启发式，不是授权。

盈利后把止损调到成本价，未必真的无损：Bid 可能低于止损、止损触发滑点、还有佣金、报价间歇、停牌、部分成交。应称「尝试保护成本」，不能说最坏必然为 0。

目标是交易权利金而不是行权接股票时，通常到期前 Sell to Close。到期前检查：合约全部为 0、没有挂单、没有意外空头、没有被行权或指派、对账单和购买力正常。

## 10.6.6 三类用途怎么选

先问自己愿意承担哪一种代价，而不是哪一种名字听起来更专业。限制下行就买保险或减仓；要强方向就付权利金并接受归零；要收权利金就按接货或交股准备现金。Warrior 叠加只决定「什么时候才允许打开期权链」，不改变这三种代价。

## 先记住这些

- 保险、杠杆、收租是三种形状，不要混用评价标准。
- 收来的权利金是最大收益。
- 先有正股的触发和失效，再选合约。
- 禁止先找最便宜的价外期权再编故事。
- 张数用最大美元风险反推，不用「一张不贵」正推。
