# 0.1 怎么读、各卷干什么

> 一句话：先按 1→4 读完再碰形态；形态在 5 和 6，过程在 8 和 9，期权从 10 起另开一条线。

编号是全书统一的：`1` 卷，`1.1` 章，`1.1.1` 节。目录在 [README](../README.md)。规则以 [附录 A](../appendix/A-current-rules.md) 为准，不以视频为准。加密货币不收。

## 0.1.1 阅读顺序

```
0.1 本页
  → 1 市场 / 账户 / 选股
    → 2 图表词汇（形状长什么样）
      → 3 报价、订单、盘口、停牌
        → 4 仓位、计划、复盘
          → 5 做多形态 或 6 做空形态（每次只读一个编号）
            → 7 用复盘检查自己有没有把形态用错
              → 8 小盘过程 或 9 大盘过程（含 VWAP 四种走法）
```

期权不是日内的前置条件。要学期权：`10 → 11 → 12`。期货和隔夜：`13`。纪律练习：`14`。

不要从 5.1 旗形开始。没有 3 和 4，形态章里的止损和股数没有着落。

## 0.1.2 各卷只回答一类问题

| 卷 | 回答 | 不回答 |
|---|---|---|
| 1 | 你在交易什么、账户规则、名单从哪来 | 具体形态的触发 |
| 2 | K 线、区域、周期、量、VWAP **是什么** | 这笔单怎么下 |
| 3 | Bid/Ask、订单、L2、Tape、热键、停牌、SSR | 要不要做多这只股票 |
| 4 | 股数、期望值、六栏计划、模拟到实盘 | 哪个形态最好 |
| 5 | **一个做多形态一篇**：触发、失效、失败、启发式 | 小盘日常流程 |
| 6 | **一个做空形态一篇**；6.1 是借股，不是形态 | 空头叙事、squeeze 证明 |
| 7 | 历史复盘：错在哪、仓位怎么炸 | 当作今天的信号 |
| 8 | 小盘：筛选、风险层、扫描、类型 | 再讲一遍旗形解剖 |
| 9 | 大盘过程；9.8 定义，9.9–9.12 四种 VWAP 走法 | 小盘 halt 当日常 |
| 10–12 | 期权合约 → 策略 → 高级结构 | 用期权名字替代正股计划 |
| 13 | 期货与 swing | 加密货币期货 |
| 14 | 能写进计划的约束和练习 | 160 小时录音 |

## 0.1.4 一卷之内怎么读形态章

5 和 6 的每一章结构应当相同：赌什么 → 怎么认 → 触发 → 失效 → 失败 → 启发式数字 → 何时放弃。读的时候只带走这六栏，不要带走讲师的 float 区间当定律。

同一笔成交不要同时记进 5.1 和 5.3。先写死名字，再下单。

## 0.1.5 规则和启发式

附录 A 管监管事实（保证金、T+1、LULD、SSR、行权）。正文和视频冲突时，信附录。

课程里的 5 倍量、10 分钟窗口、EMA 100/200、50% gap，正文里应标成**启发式**：可以当扫描器起始值，必须用自己的样本改。

## 先记住这些

- 顺序是 1→4，然后一次只读一个形态编号。
- 2.3 认形状，5.x / 6.x 做交易。
- 5.9 是开盘过程，5.11 是盘中价位，9.9–9.12 是 VWAP 走法。

## 不要做的事

- 从 5.1 或 9.9 开始学。
- 把 5.9 的 ORB 和 5.11 的 ORB 并成一个胜率。
- 用聊天室代码代替 3.6 的 reason code。
