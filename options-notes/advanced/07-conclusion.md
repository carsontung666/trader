# 高级 07：结语与风险控制

> 覆盖视频：高级第 32 讲  
> 本章时长：约 4 分钟

结语强调：高级策略的价值不在名称，而在背后的系统、验证和风险收益权衡。课程中既有通用定义，也有讲师个人经验；两者应分开对待。

![课程结语把风险控制放在策略之前](<../assets/advanced/chapter-07-conclusion/lesson-32/frame-01-0151s.jpg>)

**图怎么看：**

- 组合腿数越多，不代表风险越小；
- “过去亲自用过”只是经验，不是样本外证据；
- 系统必须包含仓位、极端情景、执行和退出规则；
- 收益潜力不能先于账户生存。

## 学完后应该能做什么

- 不看策略名称，也能逐腿写出权利和义务；
- 画出到期 Payoff，并解释到期前为何会不同；
- 区分净 Debit/Credit、保证金、购买力和最大亏损；
- 判断 Delta、Gamma、Theta、Vega 在不同价格与期限下如何变化；
- 识别 Short Option 的指派、Pin、跳空和流动性风险；
- 区分课程事实、经验规则、回测结果和个人观点；
- 在交易前写清最大损失，而不是亏损后再决定怎么办。

## 把任何策略还原成同一张表

| 问题 | 必须给出的答案 |
|---|---|
| 市场观点 | 方向、幅度、发生时间、IV |
| 结构 | 每条腿的 Buy/Sell、Call/Put、Strike、Expiry |
| 现金流 | 净 Debit 或 Credit，包含费用与滑点 |
| 到期边界 | 最大利润、最大亏损、盈亏平衡 |
| 路径风险 | Gamma、Vega、提前指派、跳空、流动性 |
| 仓位 | 最坏损失占账户比例，指派后所需现金 |
| 退出 | 价格失效、时间失效、盈利目标、到期处理 |
| 证据 | 理论、样本内回测、样本外结果还是单个案例 |

## 课程观点的使用层级

1. **定义与恒等式**：用公式、合约规则和权威资料核对；
2. **策略机制**：用 Payoff、Greeks 与情景表验证；
3. **参数经验**：把期限、Delta、止盈等视为待测试假设；
4. **历史案例**：只用来理解机制，不用来估计胜率；
5. **回测模型**：检查成本、样本外、参数稳定性和幸存者偏差；
6. **实盘应用**：先模拟或极小 Defined-Risk 仓位，再决定是否扩大。

## 最后的硬规则

- 不卖自己无法接货的 Put；
- 不裸卖自己无法承受的 Call；
- 不把 Credit 当成利润或安全垫；
- 不把 Roll 当成删除亏损；
- 不把止损价当成跳空后的成交保证；
- 不把高胜率当成正期望；
- 不把异动大单当成内幕事实；
- 不依赖自动到期处理多腿仓位；
- 不使用会让一次错误永久退出市场的仓位。

下一步不是寻找更复杂的策略，而是挑一个最简单、最大亏损明确的结构，完整记录假设、成交、Greeks、退出与复盘。
