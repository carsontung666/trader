# 初级 05：对冲、杠杆与收取权利金

> 覆盖视频：初级第 13–15 讲  
> 本章时长：约 20 分钟

## 1. Protective Put：给持仓限定下行

持有股票并买入 Put：

```text
Protective Put = Long Stock + Long Put
```

到期时，Put 把股票最低卖出价锁定在行权价，但保险不是免费的。

```text
保护后的最低组合价值 ≈ Put 行权价 − Put 权利金
```

![SPY Put 对冲案例](<../assets/beginner/chapter-05-uses-and-examples/lesson-15/frame-01-0230s.jpg>)

**图怎么看：**

- 课程案例用一张 SPY Put 对冲较大的股票组合；
- Put 在市场下跌时上涨，减小了组合的短期回撤；
- 市场反弹后 Put 最终亏损，不代表保险“失败”；评价应看整个组合是否实现风险目标；
- 一张 SPY Put 的 Delta 和名义金额未必正好匹配组合，不能只凭“买一张”判断对冲比例。

对冲前应写清楚：

- 要保护哪个标的或哪个组合；
- 保护多长时间；
- 能接受多少免赔区间；
- 愿意支付多少权利金；
- 下跌发生后何时兑现 Put；
- 市场反弹时何时取消保险。

## 2. Long Option 的杠杆

Long Call 用较小权利金取得对上涨的非线性暴露，百分比回报可能远大于股票。但杠杆来自更高的损失速度和归零风险，不是免费收益。

![Long Call 的小资金高弹性](<../assets/beginner/chapter-05-uses-and-examples/lesson-16/frame-01-0187s.jpg>)

**图怎么看：**

- 图中用较小期权成本对应较大的标的名义价值；
- 期权涨幅远高于股票涨幅，不能简单解释为固定“28 倍杠杆”；
- 实际敏感度会随 Delta、Gamma、剩余期限和 IV 变化；
- 百分比收益很高的另一面，是权利金可能在短时间内损失大部分或全部。

短期方向交易至少要限制：

- 总权利金占账户比例；
- 到期距离；
- Bid–Ask Spread；
- 事件后 IV Crush；
- 计划持有时间；
- 最大允许亏损。

没有这些约束时，应先用模拟盘，而不是把真实亏损当学费。

## 3. Short Put：收权利金并承担接货义务

卖出 Put 后：

- 最大收益是收到的权利金；
- 盈亏平衡点为 `行权价 − 权利金`；
- 到期股价低于行权价时可能被指派买入股票；
- 股价跌到 0 时损失接近 `行权价 − 权利金`，再乘合约乘数。

![Short Put 与 Long Call 的看涨方式对比](<../assets/beginner/chapter-05-uses-and-examples/lesson-17/frame-01-0234s.jpg>)

**图怎么看：**

- 两者都可表达看涨，但收益结构完全不同；
- Long Call 需要较大上涨覆盖权利金，收益上限高；
- Short Put 在横盘、小涨或有限下跌时也可能盈利，但上行收益被锁定在权利金；
- “胜率更高”必须连同尾部亏损一起评估。

假设股价 147，卖出 145 Put 收 3：

```text
最大收益 = 3 × 100 = 300 美元
盈亏平衡 = 145 − 3 = 142 美元
最坏到期损失 = (145 − 3) × 100 = 14,200 美元
```

这里的 300 美元收入对应的是承担最多约 14,200 美元风险和接货义务，不能类比为无风险“租金”。

![不同行权价 Short Put 的权利金与概率权衡](<../assets/beginner/chapter-05-uses-and-examples/lesson-17/frame-02-0433s.jpg>)

**图怎么看：**

- 更低的 Put 行权价通常更远 OTM，收到的权利金也更少；
- 到期不被指派的概率可能提高，但风险并没有消失；
- 极端下跌时，多个“高胜率”月份的权利金可能被一次亏损抵消；
- 把单月 2% 直接乘 12 年化为 24%，忽略了复利、空仓期、亏损月和保证金变化，不应作为收益承诺。

## 4. 收权利金不是固定现金流

Short Option 的盈亏来源包括：

- 标的价格变化；
- Theta；
- 隐含波动率变化；
- Gamma 在临近到期时带来的敏感度跳升；
- 提前指派和到期处理；
- 保证金与被迫减仓。

因此应使用“风险预算下的权利金收入”，而不是“稳定租金”思维。

## 5. 三类用途怎么选

| 目标 | 常见结构 | 主要代价 |
|---|---|---|
| 限制已有股票下行 | Protective Put | 持续支付权利金 |
| 用有限成本表达强方向 | Long Call / Long Put | 时间损耗、IV 与归零风险 |
| 愿意承担义务换取权利金 | Cash-Secured Put / Covered Call | 尾部风险或上行被封顶 |

任何情况下，先比较整个组合的最大亏损，再看收到或支付的权利金。
