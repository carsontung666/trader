# 初级 03：行权、被指派与到期处理

> 覆盖视频：初级第 9 讲  
> 本章时长：约 6 分钟

## 1. Exercise 和 Assignment

- **Exercise（行权）**：Long Option 持有人使用合约权利；
- **Assignment（被指派）**：Short Option 卖方被要求履行义务。

| 头寸 | 行权或被指派后的结果 |
|---|---|
| Long Call | 按行权价买入股票 |
| Short Call | 按行权价卖出股票 |
| Long Put | 按行权价卖出股票 |
| Short Put | 按行权价买入股票 |

标准股票期权通常对应 100 股，因此一个看似很小的期权头寸，行权后可能变成较大的股票头寸和购买力需求。

## 2. 美式和欧式

- 美式期权通常可在到期前行权；
- 欧式期权通常只能在到期时行权；
- 行权方式、结算方式和最后交易时间是不同概念，需要分别确认；
- 股票和 ETF 期权常见美式实物交割，部分指数期权可能是欧式现金结算，但不能仅凭名称猜测。

## 3. 为什么通常卖掉 Long 比提前行权更合理

若期权仍有外在价值，直接行权只实现内在价值；在市场中卖出期权通常还能收回外在价值。因此 Long 持有人很多时候选择 Sell to Close，而不是提前行权。

![卖出期权与提前行权的价值差异](<../assets/beginner/chapter-03-exercise-and-assignment/lesson-11/frame-01-0202s.jpg>)

**图怎么看：**

- 左侧表示卖出期权可同时回收内在价值和剩余外在价值；
- 右侧表示提前行权通常只实现内在价值；
- 这解释了为什么有外在价值时，理性持有人通常不提前行权；
- 但“提前行权几乎不用担心”不够严谨，Short 美式期权始终存在提前被指派可能。

## 4. 提前被指派什么时候更值得警惕

常见场景包括：

- Short Call 临近除息日，股息价值超过剩余外在价值；
- Deep ITM Put 外在价值很少，利率和持仓成本使提前行权更有吸引力；
- 合约流动性差，持有人难以用合理价格平仓；
- 到期临近，外在价值接近零。

卖方无法知道具体哪位持有人会行权，也不能依赖“市场上大多数人不会行权”来排除风险。

## 5. 到期自动处理不是完全自动无脑

美国标准期权通常存在 Exercise by Exception 流程，但实际结果还受券商规则、账户购买力、客户指令和截止时间影响。

特别注意：

- 到期时小幅 ITM 可能被自动行权；
- 券商可能因购买力不足提前平仓或提交不行权指令；
- Long 持有人可能选择不行权，或对 OTM 合约主动行权；
- 收盘后标的继续波动，可能形成 **Pin Risk**；
- Short 方直到被分配通知前都不能确认最终股票头寸。

所以“OTM 自动作废、ITM 一定自动行权”只能作为基础框架，不能代替券商的到期政策。

## 6. 到期前检查表

- [ ] 期权是美式还是欧式？
- [ ] 实物交割还是现金结算？
- [ ] 一个合约对应多少股或多少现金？
- [ ] Long 行权后是否有足够购买力？
- [ ] Short 被指派后会形成什么股票头寸？
- [ ] 是否临近除息日？
- [ ] 券商的行权指令截止时间是什么？
- [ ] 是否准备在到期前主动平仓？
