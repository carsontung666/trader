# 初级 06：保证金与流动性

> 覆盖视频：初级第 16–17 讲  
> 本章时长：约 14 分钟

## 1. 保证金不是最大亏损

保证金（Margin Requirement）是券商为支持某个头寸要求账户维持的资金或资产。它是风险控制门槛，不是策略成本，也不一定等于最大亏损。

必须区分：

- **Initial Margin**：开仓时要求；
- **Maintenance Margin**：持仓期间最低要求；
- **Buying Power**：账户还能建立多少头寸；
- **Excess Liquidity**：净清算价值超过维持保证金的缓冲；
- **Max Loss**：策略在模型或到期条件下的最大损失。

![IB 卖 Put 的保证金占用示例](<../assets/beginner/chapter-06-margin-and-liquidity/lesson-18/frame-01-0227s.jpg>)

**图怎么看：**

- 图中展示的是某一时点、某一账户和某一券商模型下的保证金估算；
- 不能把 `Current Excess Liquidity` 简单等同为“账户保证金”；
- 保证金要求会随股价、IV、集中度和券商风控变化；
- 收到 120 美元、占用 3,800 美元，不代表最大只会亏 3,800 美元。

## 2. 为什么 Short Option 会触发强平

市场不利变化时可能同时发生：

1. Short Option 价格上涨，账户净值下降；
2. 波动率上升，风险模型提高保证金要求；
3. 多个相关头寸同时恶化，集中度上升；
4. 券商提高 House Margin；
5. Excess Liquidity 快速接近零。

部分券商不会先给出传统意义的“补缴宽限期”，而是直接减仓。不要把“Margin Call”理解成一定有时间等市场反弹。

对初学者更清晰的比较方式：

- Cash-Secured Put：按可能接货的全部现金预留；
- Covered Call：以已持有股票覆盖交付义务；
- Defined-Risk Spread：用另一条腿明确限制到期最大亏损；
- Naked Short Option：保证金可能动态变化，最难管理。

选择券商时不应追求“保证金越低越好”。更低的要求意味着更容易放大仓位，也可能更快进入强平区。

## 3. 流动性为什么有一票否决权

期权合约被标的、到期日、行权价和 Call/Put 拆成大量独立市场。即使正股活跃，某一个具体合约仍可能很难成交。

检查：

- Bid–Ask Spread 的绝对值；
- Spread 占期权中间价的比例；
- Bid / Ask 挂单数量；
- 当日成交量；
- 未平仓量（Open Interest）；
- 多个相邻行权价的报价是否连续；
- 小额限价单能否在中间价附近成交。

![期权链中相对价差与流动性的比较](<../assets/beginner/chapter-06-margin-and-liquidity/lesson-19/frame-01-0311s.jpg>)

**图怎么看：**

- 不能只比较 0.20 和 0.25 的绝对价差；
- `Spread ÷ Mid Price` 更适合比较不同价格的合约；
- 但 Mid Price 不是成交保证，特别是两侧报价陈旧或数量很小时；
- 成交量、未平仓量和 Spread 要一起看，任何单一指标都不足够。

## 4. 下单方法

期权通常优先使用限价单：

1. 计算 Bid 与 Ask 的中间价；
2. 从对自己有利的价格开始；
3. 小幅调整，不追过事先接受的最差价格；
4. 订单未成交时重新检查标的是否快速移动；
5. 多腿策略尽量按组合净价下单，避免逐腿成交风险。

市价单在宽 Spread、低挂单量或快速行情中可能产生严重滑点。即使流动性好的合约，也应先看当时盘口。

## 5. 不要机械套用的经验

课程提到“近月、ATM、整数行权价、月度合约通常更活跃”。这些可以作为筛选起点，但不是固定规律：

- 某些周度合约可能比月度更活跃；
- 财报或事件前，特定到期日可能最活跃；
- Deep ITM 合约有时 Spread 很宽；
- 远期 LEAPS 可能成交量低但仍有稳定做市；
- 行权价间距由产品规则和股价共同决定，不直接等于流动性。

最终以当时可执行报价为准。

## 6. 开仓前检查

- [ ] 券商显示的是初始还是维持保证金？
- [ ] 保证金上升一倍时账户是否仍安全？
- [ ] 策略最大亏损是否单独计算？
- [ ] Bid–Ask Spread 占 Mid 的比例是多少？
- [ ] 挂单数量足够吗？
- [ ] 是否使用限价单？
- [ ] 到期或被指派后需要多少股票购买力？
