# 初级 01：期权合约的基本概念

> 覆盖视频：初级第 1–5 讲  
> 本章时长：约 39 分钟

## 1. Call 和 Put 到底买了什么

期权买方支付权利金，取得在规定期限内按行权价交易标的资产的权利；卖方收取权利金，承担被指派时履约的义务。

| 合约 | 买方取得的权利 | 买方通常希望 |
|---|---|---|
| Call | 按行权价买入标的 | 标的上涨 |
| Put | 按行权价卖出标的 | 标的下跌 |

每份合约至少要看四项：

1. 标的资产（Underlying）；
2. Call 或 Put；
3. 行权价（Strike）；
4. 到期日（Expiration）。

权利金（Premium）是取得这份权利所付的市场价格。

![房屋与汽车例子总结出的 Call 和 Put](<../assets/beginner/chapter-01-option-basics/lesson-03/frame-01-0208s.jpg>)

**图怎么看：**

- 房屋例子对应 Call：先付费锁定未来的买入价；
- 汽车例子对应 Put：先付费锁定未来的卖出价；
- 买方可以放弃不利的行权选择，卖方没有同等的单方面放弃权；
- 类比只帮助理解权利和义务，真实股票期权还涉及合约乘数、结算和券商处理规则。

![实际股票期权中的到期日、行权价和权利金](<../assets/beginner/chapter-01-option-basics/lesson-03/frame-02-0452s.jpg>)

**图怎么看：**

- 画面把 AAPL Call 和 SPY Put 与三个合约要素对应起来；
- 报价 `3.90` 通常是每股价格；标准美股股票期权常见乘数为 100，因此名义权利金通常是 `3.90 × 100 = 390 美元`；
- 公司行动后可能出现调整合约，不能在任何合约上机械假设乘数一定为 100。

## 2. 标的价格如何影响 Call 和 Put

先在“其他因素不变”的条件下理解：

- 标的上涨，Long Call 通常受益，Long Put 通常受损；
- 标的下跌，Long Put 通常受益，Long Call 通常受损；
- Short Call 与 Long Call 的合约损益方向相反；
- Short Put 与 Long Put 的合约损益方向相反。

![期权买方与卖方对股价方向的关系](<../assets/beginner/chapter-01-option-basics/lesson-04/frame-01-0250s.jpg>)

**图怎么看：**

- 左上是 Long Call，左下是 Long Put；
- 右侧强调卖方与买方的合约损益方向相反；
- “卖 Call = 看跌”过于简化。Covered Call 的卖方可能仍然长期看涨，只是不认为短期会大涨；
- “卖 Put = 看涨”也应理解为愿意在较低价格接货或认为价格不会大跌，而不是保证股价上涨。

实际期权价格不只由股价决定。即使方向看对，也可能因为时间流逝、隐含波动率下降或买卖价差而亏损。

## 3. 期权链怎么读

期权链（Option Chain）把同一标的的不同到期日、行权价、Call 和 Put 排在一起。

最先定位：

1. 标的代码和当前股价；
2. 到期日；
3. 中间的行权价；
4. 左右两侧的 Call / Put；
5. Bid、Ask 和可成交数量；
6. 成交量、未平仓量和隐含波动率。

![IB 期权链中的 Call、Put、行权价和报价](<../assets/beginner/chapter-01-option-basics/lesson-05/frame-01-0265s.jpg>)

**图怎么看：**

- 中间列是行权价，左侧为 Call，右侧为 Put；
- Bid 是市场当前较高的买价，Ask 是较低的卖价；立即买入通常更接近 Ask，立即卖出通常更接近 Bid；
- 报价乘以合约乘数才是实际权利金；
- 成交量大不必然代表此刻容易成交，还要看 Bid–Ask Spread、盘口数量和未平仓量；
- 画面是旧版 IB 界面，字段位置和可交易到期日可能已变化。

下单前不要只按“标的—策略—到期—行权价”四步机械点击，还要确认：

- 买入还是卖出；
- 开仓还是平仓；
- 合约数量与乘数；
- 限价和预估总金额；
- 最大亏损与购买力占用；
- 到期、自动行权和被指派风险。

## 4. 买方和卖方

开仓动作有四种：

| 动作 | 含义 |
|---|---|
| Buy to Open | 买入并建立多头期权 |
| Sell to Close | 卖出已有多头期权以平仓 |
| Sell to Open | 卖出并建立空头期权 |
| Buy to Close | 买回空头期权以平仓 |

“卖出已有期权”是平掉 Long；“在没有 Long 的情况下卖出开仓”才是建立 Short。Short Option 也不是先借入合约再卖出，不能照搬股票做空的理解。

![期权买卖双方的方向关系](<../assets/beginner/chapter-01-option-basics/lesson-06/frame-01-0277s.jpg>)

**图怎么看：**

- 画面用 Long/Short Call 表示看涨程度的差异；
- 买方支付权利金，卖方收取权利金，但卖方收钱并不等于已经获利；
- 卖方利润上限通常是收到的权利金，风险取决于具体头寸；
- “期权卖方亏损无限”只准确适用于某些结构，例如裸卖 Call。Cash-Secured Put 的最大亏损很大但有界，价差策略的风险也可能被限定。

合约到期损益在手续费前近似是多空双方之间的转移，但实际交易还存在佣金、价差、滑点和税费，不能把“零和”误解成买卖双方胜率必然各为一半。

## 5. ITM、ATM、OTM

这三个词描述的是行权价与当前标的价格的关系，不是这笔交易最终是否赚钱。

| 类型 | Call | Put |
|---|---|---|
| ITM（价内） | 股价 > 行权价 | 股价 < 行权价 |
| ATM（平价附近） | 股价约等于行权价 | 股价约等于行权价 |
| OTM（价外） | 股价 < 行权价 | 股价 > 行权价 |

内在价值：

```text
Call 内在价值 = max(股价 − 行权价, 0)
Put 内在价值  = max(行权价 − 股价, 0)
```

![AAPL 期权链中的 OTM Put](<../assets/beginner/chapter-01-option-basics/lesson-07/frame-01-0350s.jpg>)

**图怎么看：**

- 图中股价约为 146.87 美元，140 Put 的行权价低于股价，因此属于 OTM Put；
- OTM 不等于“没有价格”，只表示当下内在价值为零；它仍可能有时间价值；
- ITM 也不等于这笔交易盈利。例如花 10 美元买入一个内在价值只有 6 美元的期权，整体仍可能亏损；
- ATM 在现实中通常指最接近当前股价的行权价，不要求完全相等。

## 6. 一张单的最小核对表

在交易界面确认：

- [ ] 标的代码正确；
- [ ] Call / Put 正确；
- [ ] 到期日正确；
- [ ] 行权价正确；
- [ ] Buy / Sell 和 Open / Close 正确；
- [ ] 合约数量及乘数正确；
- [ ] 使用限价并检查 Bid–Ask Spread；
- [ ] 知道最大亏损和到期处理；
- [ ] 不把 ITM 当作“已经盈利”；
- [ ] 不把收到权利金当作“低风险收益”。
