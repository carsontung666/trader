## 每类文件怎么用

### 1. `03-detailed-notes`

这是主学习材料。讲义不是逐字翻译，而是把视频重组为：

- 概念解释；
- 直接显示在对应段落中的视频截图；
- 每张截图的观察顺序、证据含义与误读边界；
- 逐步交易流程；
- 案例拆解；
- 常见错误；
- 风险边界；
- 复盘模板或检查表；
- 复习题。

视频中容易误导的地方，例如只按预期利润选仓位、直接复制 Hotkey、把个人胜率当作普遍结论、把幸运脱困当作策略，都在讲义中单独标出。

目前 9 份讲义共内嵌 **70 张关键视频帧**：

- 概念课优先展示讲师的定义页与对应图表；
- Level 2、Hotkey 和 Locate 课程同时展示界面字段与实际盘面；
- GME / AMC 与 INVO 案例按时间顺序展示入场、失效、退出和“不交易”；
- 每张图后都有“图 X-X 怎么看”，说明应先看哪里、画面支持什么结论，以及不能从单张截图推出什么。

图片默认使用原视频 1080p 帧；文字或盘口较小时，可点击图片查看原图。

### 2. `01-transcripts`

自动转写稿用于查找原话和时间位置：

- `.md`：最方便阅读，带时间戳；
- `.srt`：可作为字幕载入播放器；
- `.json`：保留分段和词级时间，适合以后做检索或其他处理。

转写由语音识别自动生成，仍可能出现人名、股票代码、英文术语或同音词错误。遇到转写稿和详细讲义不一致时，优先结合讲义中内嵌的视频截图、上下文和人工修正理解。

### 3. `02-visual-index`

每个视频有独立文件夹：

- `frame_001.jpg`、`frame_002.jpg`……：约每 20 秒一张；
- `contact-sheet-00.jpg`、`contact-sheet-01.jpg`……：把多张画面排成一页。

需要确认讲师当时画的阻力线、Level 2 数量、券商报价或实际 K 线时，先看联系表，再打开对应单帧。

## 核心术语表

### 价格与图表

**Candlestick / K 线**  
用开盘、最高、最低和收盘价格表示一个时间区间内的走势。

**Daily Chart / 日线图**  
每根 K 线代表一个交易日。课程用它寻找较长期阻力和均线位置。

**EMA / Exponential Moving Average**  
指数移动平均线，近期价格权重更高。课程中的 Daily EMA 指日线级别 EMA。

**VWAP / Volume-Weighted Average Price**  
成交量加权平均价。表示当日成交价格按成交量加权后的平均水平。

**Whole Dollar / Half Dollar**  
整数位和半美元位，例如 3.00、3.50。它们常因心理和挂单集中形成短期支撑或阻力。

**Resistance / 阻力**  
价格上涨到某一区域后更容易遇到卖压，不代表必然反转。

**Support / 支撑**  
价格下跌到某一区域后更容易遇到买盘，不代表一定守住。

**Confluence / 信号叠加**  
多个相互独立的依据出现在同一区域，例如历史阻力、EMA 和整数位重合。

### 趋势

**Higher High / HH**  
新的波段高点高于前一个波段高点。

**Higher Low / HL**  
新的回调低点高于前一个回调低点。

**Lower Low / LL**  
新的波段低点低于前一个波段低点。

**Lower High / LH**  
反弹高点低于前一个反弹高点。

**Consolidation / 盘整**  
价格在一个区间内来回波动，没有清晰延续方向，通常需要等待突破确认。

**Breakout / 突破**  
价格越过前高、阻力或区间边界。突破后仍可能失败。

**False Breakout / 假突破**  
价格短暂越过关键位置，随后迅速回到原区间。

### 盘口与订单

**Level 2**  
显示多个价位上的可见买卖挂单。它能提供上下文，但订单可撤销，不能单独证明未来方向。

**Bid**  
当前买方愿意出的价格。

**Ask**  
当前卖方愿意接受的价格。

**Spread**  
最佳 Bid 与最佳 Ask 的差值。

**Hidden Buyer / Hidden Seller**  
实际持续成交数量明显大于可见挂单数量时，可能存在隐藏或不断补充的订单。

**Market Order**  
优先立即成交，不保证价格。在低流动性股票中可能产生较大滑点。

**Limit Order**  
限定最差成交价格，但不保证成交。

**Stop Market**  
价格触发后转为市价单，强调退出但不保证成交价。

**Stop Limit**  
触发后转为限价单，限制价格，但快速行情中可能完全无法成交。

**Range Order**  
课程中的成对止盈与止损工具。实际是否互相取消、部分成交如何处理，取决于平台和券商实现。

**Breakeven / 保本价**  
通常指平均持仓成本附近。严格计算时还要考虑佣金、平台费、借股费和滑点。

### 做空与暂停

**Short / 做空**  
先借入并卖出股票，希望以后以更低价格买回。股价上涨会造成亏损，理论亏损上限不像做多那样受买入成本限制。

**Cover / 回补**  
买入股票以关闭空头仓位。

**Locate**  
券商为难借股票寻找或预留可借股份的流程或库存。Locate 并不等于已经建立空头仓位。

**Borrow Fee / Locate Fee**  
借股或预留股份产生的费用。不同券商、股票和时间可能完全不同。

**Short Squeeze / 轧空**  
价格上涨迫使空头买入回补，回补买盘又进一步推高价格。

**Halt / Trading Pause**  
股票临时停止交易。暂停期间普通交易者无法正常退出，恢复时可能跳空。

**LULD / Limit Up–Limit Down**  
美国市场用于限制个股异常短期波动的价格带机制。它不是 A 股每日固定涨跌停制度。

**Imbalance / 订单不平衡**  
在开盘、恢复或拍卖阶段，买卖需求之间的不平衡信息。它可能影响参考价格，但不是最终成交保证。

### 风险与复盘

**Position Size**  
持仓股数。更稳健的基础计算是：

```text
股数上限 = 单笔最大可承受亏损 ÷ 每股止损距离
```

随后还应受到购买力、流动性、滑点、暂停风险和平台限制约束。

**Gross Profit / 毛利**  
尚未扣除所有交易成本的盈亏。

**Net Profit / 净利**  
扣除佣金、平台费、借股费、监管费和其他成本后的结果。

**Slippage / 滑点**  
预期成交价与实际成交价之间的差异。

**Risk–Reward / 风险收益比**  
计划承担的亏损与预期收益之间的关系。它只是计划工具，不代表达到目标的概率。

**Invalidation / 失效条件**  
入场逻辑不再成立的可观察条件。它比“我感觉还能回来”更适合作为退出依据。

## 一套省时间的学习方法

每课可以只用 20–30 分钟完成：

1. 先读讲义开头的学习目标；
2. 通读概念和流程；
3. 只打开讲义链接的关键画面；
4. 不懂时再查看对应时间戳转写和画面索引；
5. 不看答案写一遍复习题；
6. 用自己的话写一句“这节课何时不能用”。

第 7、8、9 课涉及自动订单、暂停和高波动小盘股，建议至少读两遍风险部分，不要跳过失败案例。

## 最后提醒

这套材料的作用是帮你理解视频，不是替你证明某个策略有效。学习时要把三类信息分开：

1. **事实**：视频画面中实际发生了什么；
2. **讲师判断**：他当时为什么认为应该买、卖或等待；
3. **可验证规则**：你自己的账户、券商和当前市场是否仍然允许或支持相同操作。

只有第一类可以从视频直接确认；第二类需要复盘；第三类必须在真实操作前重新查证。
