## 怎么查

- 想找选股、scanner、news、watchlist：在这些年份文件中搜索 `stock selection`、`scanner`、`news`、`watchlist`。
- 想找图表与策略：搜索 `breakout`、`pullback`、`reversal`、`VWAP`、`moving average`、`Fibonacci`。
- 想找执行：搜索 `Level 2`、`tape`、`hotkey`、`stop`、`position size`、`trade management`。
- 想找流程与复盘：搜索 `journal`、`review`、`process`、`discipline`、`routine`。

录制时间为 2018–2021 年。平台界面、费用、保证金、借股、税务和监管条件只按历史内容理解，实际使用前需要回到当前券商和监管机构的官方资料确认。
