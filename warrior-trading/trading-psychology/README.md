# Trading Psychology

模块 07 共整理 184 场录制，合计 160.1 小时，分为 Mindful Monday 与 FOMO Friday。

Mindful Monday 偏向觉察、呼吸、情绪命名、价值观和日常训练；FOMO Friday 更集中处理追涨、冲动、亏损后反应、规则违约和周度复盘。两者有交叉，正文保留每场的具体练习与交易情境。

## 使用方式

- 先读“本场重点”和“风险与边界”，判断是否对应自己的问题。
- 练习类内容一次只选一个动作，例如开盘前呼吸、情绪命名或触发后暂停。
- 用交易日志验证练习是否改变了追单次数、超额仓位、移动止损和 revenge trading，不要只记录当天心情。
- 心理训练不能替代仓位上限、最大损失、订单检查和平台风控。
