# Options Trading Course

这 5 节是压缩包里的独立 Options Trading 系列，不并入模块 04 的 Swing and Options。课程重点是用股票技术分析寻找短线方向，再选择 strike/expiration 交易 premium。

- [Foundations and leverage](01-foundations-and-leverage.md)
- [Technical analysis and watchlist](02-technical-analysis-and-watchlist.md)
- [Premium, Greeks, and option chain](03-premium-greeks-and-option-chain.md)
- [Trade planning and risk](04-trade-planning-and-risk.md)

课程偏好短期限、略微 OTM 的 long options，这只是讲师风格，不是通用最优解。Options 具有时间衰减、波动率、spread、exercise/assignment 和到期风险；开始前应阅读当前 OCC Options Disclosure Document。

当前官方参考：

- [OCC：Characteristics and Risks of Standardized Options](https://www.theocc.com/company-information/documents-and-archives/options-disclosure-document)
- [FINRA：Options](https://www.finra.org/investors/investing/investment-products/options)
