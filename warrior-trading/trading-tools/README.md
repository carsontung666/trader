# Trading Tools and Layouts

对应模块 05，共 12 个视频。这里不按软件逐项抄菜单，而是把界面配置转成可执行的检查表：哪些窗口必须存在、如何联动、哪些默认值最容易造成错误，以及各类工具解决什么问题。

- [Direct-access platforms](01-direct-access-platforms.md)：Sterling、Lightspeed、DAS 的布局、订单窗口、热键和风险设置
- [Scanners and news](02-scanners-and-news.md)：Trade Ideas、Benzinga Pro、Primus
- [Charting platforms](03-charting-platforms.md)：eSignal、TC2000
- [Broker platforms](04-broker-platforms.md)：thinkorswim、TradeZero、E*TRADE

平台界面、费用、数据包、路由和开户资格都会变化。截图反映的是录制时的软件版本；真正可复用的是窗口分工、订单核对和故障预案。
